## Усталость мышц

Реализовать canonical model:

* `fatigueScore`;
* `fatigueDelta` после упражнения;
* события усталости;
* snapshot-таблицу текущего состояния;
* `lastFatigueCalculatedAt`;
* `recoveryHalfLifeHours`;
* пересчёт через фактическое время;
* поддержку случая, когда сервер был выключен;
* значения выше `100` как перегруз;
* `readinessPercent = clamp(100 - fatigueScore, 0, 100)`.

Критическое правило: восстановление нельзя считать таймером в памяти. Только через persisted timestamp и фактическую разницу `nowUtc - lastFatigueCalculatedAt` или через event-based пересчёт.

## Acceptance criteria

* Frontend-экраны этапов 3 и 4 могут читать реальные результаты и прогресс.
* После упражнения создаются события усталости по мышцам.
* После перезапуска backend усталость пересчитывается по фактическому времени.
* Значения `7 из 100`, `72 из 100`, `150 из 100` корректно отображаются в API.
* Фото прогресса загружаются, отображаются, сравниваются и удаляются через безопасный сценарий.
* Графики прогресса строятся по backend-агрегатам.
* Аналитические расчёты покрыты unit-тестами.
