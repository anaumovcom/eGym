# Этап 10 — Production release и эксплуатация

## Цель

Подготовить Forma к полноценному запуску: сборка, деплой, обновления, бэкапы, мониторинг, инструкции, эксплуатационные процедуры и безопасный релиз.

---

## Production packaging

Подготовить:

* production-сборку frontend;
* production-сборку backend;
* конфигурацию окружений;
* миграции БД;
* storage для фото;
* Redis;
* hardware service;
* emulator mode для тестовых стендов;
* local/edge deployment profile.

---

## Обновления

Реализовать стратегию:

* версия приложения;
* версия схемы БД;
* версия firmware/protocol, если применимо;
* безопасное применение миграций;
* rollback-план;
* уведомление пользователя о критических обновлениях;
* запрет тренировки во время опасного обновления.

---

## Наблюдаемость

Настроить:

* backend logs;
* frontend error reporting;
* hardware logs;
* audit log;
* safety events;
* performance metrics;
* health checks;
* storage usage;
* backup status;
* alerting для критических ошибок.

---

## Резервные копии

Реализовать:

* backup PostgreSQL;
* backup фото прогресса;
* backup пользовательских программ;
* backup калибровок;
* backup системных настроек;
* проверку восстановления;
* расписание резервного копирования;
* ручной экспорт.

---

## Документация эксплуатации

Подготовить:

* инструкцию запуска;
* инструкцию обновления;
* инструкцию восстановления из backup;
* инструкцию диагностики приводов;
* инструкцию сервисного режима;
* процедуру аварийной остановки;
* процедуру замены/сброса калибровок;
* чек-лист перед демонстрацией или эксплуатацией.

---

## Release checklist

Перед релизом проверить:

* все E2E-сценарии;
* безопасность `СТОП`;
* запуск упражнения с калибровкой и без неё;
* live-статусы;
* фото прогресса;
* восстановление усталости после выключения сервера;
* восстановление после backend restart;
* восстановление после frontend reload;
* backup restore;
* отсутствие тестовых моков в production mode.

---

## Acceptance criteria

* Приложение разворачивается воспроизводимо.
* Есть инструкции запуска и обслуживания.
* Есть стратегия обновления и отката.
* Есть резервное копирование и проверка восстановления.
* Есть мониторинг и журнал критических событий.
* Production mode не использует моковые данные.
* Релизная версия проходит полный чек-лист безопасности.
