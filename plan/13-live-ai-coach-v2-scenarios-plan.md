## 1. Цель

Сделать тренировку историей с характером: перед стартом пользователь выбирает сценарий,
тренер ведёт сюжет от разминки до финала, реагирует на то, что реально измеряет тренажёр
(темп, скорость, паузы, рекорды, объём), говорит с эмоцией, которая соответствует моменту,
и в конце выдаёт «эпизод» с итогами.

Что не меняется (требования раздела 2 плана U00–U10 остаются в силе):

- Тренер не управляет тренажёром, не меняет вес, план и калибровку.
- Числа, сравнения и рекорды — только из `allowedFacts`, ИИ их не вычисляет.
- Сценарий не может требовать повторов, веса или подходов сверх плана.
- Наблюдения тренажёра формулируются как наблюдения тренажёра: «скорость упала»,
  а не «ты устал» или «у тебя болит».
- Счёт повторов и безопасность работают без сети и без бюджета.
- Все платные попытки, включая предгенерацию и неуспешные, учитываются в ledger.
- Микрофона нет: тренер не задаёт вопросов, требующих ответа голосом.

## 3. Экономика (ориентир для V0)

По текущей конфигурации ([config.py](../backend/app/core/config.py)):

- Текст `gpt-6-luna`: $0.10 / 1M входных, $0.01 / 1M кешированных, $0.50 / 1M выходных
  токенов. Реплика с промптом ~4k токенов и ответом ~600 токенов стоит ≈ $0.0007.
  200 реплик ≈ **$0.15**, даже с best-of-3 и судьёй ≈ **$0.5**.
- Голос Fish drama-3: $50 / 1M байт UTF-8. Кириллица — 2 байта на символ.
  Реплика 120 символов ≈ 240 байт ≈ **$0.012**. Это основная статья расходов.
  $3.5 на голос ≈ 290 реплик среднего размера ≈ 40–50 минут речи.

Вывод: деньги тратятся на голос, а не на текст. Поэтому:

- best-of-N и судья делаются **по тексту**, синтезируется только победитель;
- рассуждение и большие лимиты токенов почти не влияют на стоимость;
- предгенерация голоса (V8) должна покрывать только реплики, которые точно прозвучат.

Лимиты (решение D-V02.1 от 25.10.2026, **уже внесено в код**): до **$10** на тренировку,
**$20** в сутки, $100 в месяц. Доли ниже — от фактического лимита пользователя;
пример для $10:

| Статья | Доля | Сумма при $10 |
|---|---|---|
| Генерация сценария и библии (V1) | 2% | $0.20 |
| Предгенерация голоса сценария (V8) | 20% | $2.00 |
| Live-реплики: текст | 8% | $0.80 |
| Live-реплики: голос | 52% | $5.20 |
| Резерв на итог и эпизод (V11) | 10% | $1.00 |
| Запас на неуспешные попытки | 8% | $0.80 |

$5.20 на live-голос ≈ 430 реплик. Реально тренировка на 60 минут в «Шоу» тратит
порядка $3–5; $10 — запас, а не целевой расход.

## 6. V2 — телеметрия повторов (#9, #10, #11, #14)

**Результат:** тренер знает начало повтора, фазу, темп, падение скорости и паузы.

## 9. V5 — модель настроения и отбор по новизне (#21, #20)

### V5.1. Настроение (#21)

`backend/app/services/coach/mood.py` — детерминированный автомат:

| Настроение | Когда |
|---|---|
| `warmup` | первый акт, первые подходы |
| `focus` | подход идёт ровно |
| `grind` | падение скорости ≥ 15%, последние повторы, последний подход |

| `comeback` | полный подход после частичного |
| `recover` | после частичного/пропуска; без юмора и подколов |
| `finale` | последнее упражнение и итог |

- [ ] Вход: наблюдения V2/V3, результат подхода, акт, прогресс.

### V6.0. Справочник возможностей Fish

#### Что использует код сейчас

[voice.py](../backend/app/services/coach/voice.py) `fish_markup` / `FishVoiceAdapter.request`:

- одна общая ремарка в начале `[...]` на русском (до 60 символов от автора или из `FISH_ENERGY`/`FISH_PROFILE`);
- один звук перед репликой из 6: laugh, chuckle, smirk, sigh, exhale, whistle (переводятся в русские ремарки);
- один парный тег на **последнем** предложении из 6: whisper, emphasis, forceful, soft, fast, slow
  (тег `<stress>` не используется);
- в теле запроса только `text`, `format=pcm`, `sample_rate`, `latency=balanced`, `reference_id`;
  `temperature`, `top_p`, `prosody`, `normalize`, `language` не передаются (значения по умолчанию).

Не используются: эмоции по предложениям, паузы, звуки внутри реплики, эффекты зала,
несколько голосов, параметры скорости/громкости/вариативности, словари произношения.

#### drama-3: родной синтаксис

| Средство | Синтаксис | Примечание |
|---|---|---|
| Ремарка | `[свободное описание] текст` | Эмоция, намерение, темп, к кому обращается — «как актёру». На любом языке. Действует на следующий за ней текст; можно ставить перед каждым предложением |
| Звук / пауза | `[sigh]`, `[small laugh]`, `[shaky breath]`, `[short pause]` | Ставится ровно там, где должен прозвучать |
| Парные теги (7) | `<whisper>`, `<emphasis>`, `<soft>`, `<fast>`, `<slow>`, `<stress>`, `<forceful>` | Меняют подачу только обёрнутых слов |
| Смена языка (эксперим.) | `<english>…</english>`, `<french>`, `<spanish>`, `<german>`, `<japanese>`, `<chinese>`, `<korean>`, `<italian>` | Только обёрнутые слова; точность зависит от голоса |
| Фонемы | `<\|phoneme_start\|>…<\|phoneme_end\|>` | Только английский (Arpabet), китайский, японский — для русского не подходит |
| Несколько голосов | `<\|speaker:0\|>…<\|speaker:1\|>…` + `reference_id: [id0, id1]` | Целая сцена одним запросом |

#### Каталог эмоций S2 (используем как словарь ремарок для drama-3)

Документ описывает S2-синтаксис `[tag]`; drama-3 принимает ремарки свободной формой,
поэтому эти слова пригодны как ремарки. Перед включением проверяется прослушиванием (V6.7).

- **Базовые (24):** happy, sad, angry, excited, calm, nervous, confident, surprised, satisfied,
  delighted, scared, worried, upset, frustrated, depressed, empathetic, embarrassed, disgusted,
  moved, proud, relaxed, grateful, curious, sarcastic.
- **Расширенные (25):** disdainful, unhappy, anxious, hysterical, indifferent, uncertain, doubtful,
  confused, disappointed, regretful, guilty, ashamed, jealous, envious, hopeful, optimistic,
  pessimistic, nostalgic, lonely, bored, contemptuous, sympathetic, compassionate, determined, resigned.
- **Тон (6):** in a hurry tone, shouting, screaming, whispering, soft tone, emphasis.
- **Звуки (11):** laughing, chuckling, sobbing, crying loudly, sighing, groaning, panting, gasping,
  yawning, snoring, clear throat. После звука нужен текст-пара: «Ха-ха-ха», «Хе-хе», «Эх»,
  «Уф», «Фух-фух», «Ах!», «Зззз», «Кхм».
- **Спецэффекты (5):** audience laughing, background laughter, crowd laughing, break, long-break.
- **Интенсивность:** `[slightly …]`, `[very …]`, `[extremely …]`.
- **Комбинации:** `[sad][whispering]`; не более ~3 эмоций на предложение.

Правила из документации: одна главная эмоция на предложение; эмоция в начале предложения;
тон и звуки — в любом месте; не перегружать короткий текст; не смешивать противоречивые эмоции;
короткие описания; менять эмоции не слишком часто. Теги не увеличивают задержку.

#### Параметры API, которые можно использовать

| Параметр | Диапазон | Как используем |
|---|---|---|
| `temperature` | 0–1, по умолч. 0.7 | Выше — живее, ниже — стабильнее (V6.5) |
| `top_p` | 0–1, по умолч. 0.7 | Вместе с temperature |
| `prosody.speed` | 0.5–2.0 | Темп по фазе и настроению |
| `prosody.volume` | дБ | Громкость по интенсивности, согласовать с микшером |
| `prosody.normalize_loudness` | bool | Документирован для S2; для drama-3 проверить |

| `normalize` | bool | Числа уже прописаны словами в [facts.py](../backend/app/services/coach/facts.py) — проверить `false` |

  второстепенные ремарки (сначала интенсивность, потом звуки, эмоция предложения — последней).
- [ ] Ledger уже считает байты фактического `text`; добавить в диагностику долю разметки.
- [ ] Промо-цена drama-3 $10 / 1M байт (в 5 раз дешевле) действует **до 12.11.2026 17:00 UTC** —

- [ ] Предгенерация длится, пока пользователь готовится; нельзя задерживать старт.
- [ ] Параметры синтеза для предгенерации: `latency=normal` и `features=["quality-guard"]` (V6.5) —

**Критерий выхода:** вступления и переходы звучат без сетевой задержки; изменение плана
не приводит к устаревшей реплике; затраты на предгенерацию ≤ 20% бюджета.
