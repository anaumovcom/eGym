# V2: итог реализации и локальной проверки

## Реализовано и проверено

- Правила `achievements-rules-1.3.0`: 120 исходных линий получили различающиеся
  обязательные профили дней доказательства. Исторические числовые вехи и ID сохранены
  намеренно ради совместимости оплаченных текстов, а не объявлены повышенными.
- Общая коллекция содержит 152 линии / 515 ступеней: core 120 / 387 и
  существующие 32 exercise/muscle линии / 128. Интеграция последних уже была в коде
  до текущего прохода; они не были заново сгенерированы в этом проходе.
- Исправлены зачёт незавершённых/синтетических записей, преждевременная знакомость
  упражнения, ложное завершение программы и пересечение независимых наборов дней.
- API/UI показывают фактические дни и обязательные дни каждой ступени; процент
  ограничивается обоими условиями. Каталог поддерживает переменное число ступеней.
- Reconcile архивирует исходный каталог и сохраняет оплаченные редакционные поля.
  Регрессия сравнивает существующие 503 оплаченных текста без перезаписи.
- Существующая Windows-схема ledger (unique temp, fsync, atomic replace, retry,
  recovery receipt, job lock) проверена тестами; глобальные обязательства не сброшены.
- Audio resume требует валидный WAV и совпадающий SHA256. Итоговый audit учитывает
  ошибки валидации, а не только наличие файлов. OpenAPI обновлён.

## Проверки

- Focused backend pytest: **141 passed**.
- Ruff по achievements service/schema/generation/audit и изменённым тестам: clean.
- Frontend focused Vitest: **7 passed**, без прежнего act/pause шума.
- Изолированный Playwright Chromium: **3 passed**, 360 / 1920 / 3840 px,
  динамические counts, шесть ступеней, требования по дням, отсутствие overflow.
- Vite production bundle: успешно. Полный frontend build не зелёный:
  TypeScript сообщает 23 ошибки в семи модулях вне achievements (photo-progress,
  mocks/stage4-data, quick-start, settings, today, exercise-details-dialog,
  runtime-store). Исправление этих посторонних модулей не выполнялось.
- Editor diagnostics в проверенных изменённых файлах: ошибок нет.
- Git diff whitespace check: без ошибок (есть предупреждения о LF/CRLF).

Тесты использовали fixture-БД и перехваты API/WebSocket. Реальная пользовательская
БД, миграции/backfill и оборудование не запускались. Платная коллекция остаётся
неполной до разрешения неизвестных результатов запросов и WAV quality blocker.
