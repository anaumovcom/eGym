# Проверка интерфейса Forma

Единственный целевой экран — полноэкранный киоск 4K (3840×2160 физических пикселей) при масштабе ОС 150% и масштабе браузера 100%. Все визуальные проверки и скриншоты выполняйте в этом режиме. Для браузерных тестов используйте общий профиль `frontend/e2e/kiosk-display.mjs` с областью просмотра 2560×1440 CSS-пикселей и `deviceScaleFactor: 1.5`.

Образец основного меню — верхняя панель страницы `/fatigue`. Для всех страниц с меню используйте `TopNavigationMenu`. Порядок ссылок и правила оформления приведены в [общих правилах навигации](docs/common/ui-and-navigation.md#основное-меню).
