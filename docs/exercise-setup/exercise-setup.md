# Экран 11 — Настройка упражнения

## Назначение экрана

Экран **“Настройка упражнения”** открывается перед началом выполнения упражнения.

Главная задача экрана — дать пользователю быстро и понятно настроить:

- нагрузку;
- количество подходов;
- количество повторов или время;
- отдых;
- режим нагрузки;
- готовность к выполнению;
- диапазон движения, если упражнение требует калибровки.

Калибровка на этом экране не является главным смыслом.  
Она отображается только тогда, когда нужна.

---

## Главное правило экрана

```text
Настройка упражнения = настройка нагрузки и параметров выполнения.

Калибровка = дополнительный блок, который появляется только для упражнений,
где тренажёр управляет движением грифа или рукояти.
```

---

## Когда открывается экран

Экран открывается после нажатия кнопки **“Начать”** из разных мест приложения:

```text
Быстрый старт → Настройка упражнения
Сегодняшняя тренировка → Настройка упражнения
Каталог упражнений → Быстрый старт → Настройка упражнения
Карточка упражнения → Настройка упражнения
Библиотека программ → Настройка упражнения
Календарь → Сегодняшняя тренировка → Настройка упражнения
```

Если нужно сделать фото прогресса, оно показывается до этого экрана:

```text
Нажать “Начать”
→ Фотофиксация прогресса, если требуется
→ Настройка упражнения
→ Выполнение упражнения
```

Отдельного экрана предстартовой проверки нет. Проверка готовности тренажёра, зоны движения, приводов, безопасности и калибровки выполняется на этом экране в блоках `Диапазон движения / калибровка` и `Готовность к упражнению`.

---

# Основные варианты экрана

Экран должен поддерживать 3 основных состояния:

| Вариант                     | Когда используется                                              |
| --------------------------- | --------------------------------------------------------------- |
| **Калибровка сохранена**    | Упражнение требует диапазон движения, и он уже был задан ранее. |
| **Калибровка не найдена**   | Упражнение требует диапазон движения, но данных ещё нет.        |
| **Калибровка не требуется** | Упражнение выполняется без тренажёра или без управления грифом. |

# Верхняя системная панель

Верхняя панель единая для всего приложения Forma.

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод подключён]
[Правый привод подключён]
[Безопасность включена]
[СТОП]
```

## Кнопка `СТОП`

Кнопка аварийной остановки должна быть всегда видна.

Требования:

* крупная;
* красная;
* расположена справа сверху;
* доступна в любом состоянии экрана;
* при нажатии сразу блокирует движение тренажёра.

# Общая структура экрана

Экран состоит из 5 основных зон:

1. Карточка упражнения.
2. Настройка нагрузки и объёма.
3. Режим нагрузки.
4. Диапазон движения / калибровка.
5. Готовность к упражнению и кнопка старта.

---

# Блок 1 — Карточка упражнения

## Назначение

Показывает, какое упражнение сейчас будет выполняться.

## Содержимое

```text
Жим с пола со штангой
Barbell Floor Press

[Видео 16:9]

Грудь
Трицепс
Штанга
Продвинутый
```

## Видео

Все видео упражнений имеют горизонтальный формат:

```text
1280×720
16:9
mp4
```

Видео на этом экране нужно для быстрого визуального напоминания упражнения.

## Метки упражнения

Пример:

```text
Грудь
Трицепс
Штанга
Продвинутый
```

Для упражнений без тренажёра:

```text
Отжимания
Push-Ups

Грудь
Плечи
Трицепс
Кор
Собственный вес
```

---

# Блок 2 — Нагрузка и объём

## Назначение

Главный блок экрана.
Пользователь должен быстро настроить параметры выполнения.

---

## Для упражнения с весом

Пример:

```text
Нагрузка

40 кг
Шаг: 2.5 кг

[-] [+]
```

Дополнительно:

```text
Подходы: 3
Повторы: 10
Отдых: 90 сек
```

---

## Управление весом

Вес должен быть крупным и центральным элементом блока.

```text
40 кг
```

Кнопки:

```text
[-]
[+]
```

Можно добавить быстрые шаги:

```text
-5 кг
-2.5 кг
+2.5 кг
+5 кг
```

---

## Для упражнения с собственным весом

Например, отжимания:

```text
Нагрузка

Собственный вес
Без отягощения
```

Параметры:

```text
Подходы: 3
Повторы: 12
Отдых: 60 сек
```

---

## Для упражнения на время

Например, планка или растяжка:

```text
Подходы: 3
Время: 45 сек
Отдых: 45 сек
```

---

# Блок 3 — Режим нагрузки

## Назначение

Показывает, как именно тренажёр будет создавать нагрузку.

Для упражнений с тренажёром:

```text
Обычный вес
Помощь вверх
Негативная фаза
Лёгкий режим
```

## Пример

```text
Режим нагрузки

[Обычный вес] [Помощь вверх] [Негативная фаза] [Лёгкий режим]
```

Активный режим подсвечивается золотым цветом.

Если вариантов режима много или нужно объяснение, кнопка `Изменить` открывает `LoadModeModal` по правилам:

```text
docs/common/modals-panels-overlays.md
```

В модальном окне показываются краткое описание режима, влияние на нагрузку и ограничения безопасности.

---

## Для упражнений без тренажёра

Если упражнение не использует тренажёр, блок меняется:

```text
Режим

[Без тренажёра] [Изометрия] [Темповый режим] [Паузы]
```

Пример для отжиманий:

```text
Без тренажёра
```

---

# Блок 4 — Рекомендация Forma

## Назначение

Показывает рекомендацию по нагрузке и объёму.

## Пример для упражнения с весом

```text
Рекомендация Forma

Оставить 40 кг.
Можно увеличить до 42.5 кг, если чувствуете себя хорошо.
```

## Пример для упражнения с собственным весом

```text
Рекомендация Forma

Текущий объём оптимален.
Сохраняйте 3×12 для прогрессии силы и выносливости.
```

## Если есть усталость мышц

```text
Рекомендация Forma

Грудь имеет умеренную усталость.
Лучше оставить текущий вес или немного снизить объём.
```

---

# Блок 5 — Диапазон движения / калибровка

## Главное правило

Блок калибровки не должен занимать много места, если калибровка уже есть.

Калибровка становится главным блоком только если:

* калибровки нет;
* пользователь нажал `Откалибровать`;
* пользователь решил изменить диапазон;
* сохранённая калибровка устарела.

---

# Вариант 1 — Калибровка сохранена

## Как отображать

Компактный блок:

```text
Диапазон движения

Сохранён

64–132 см

[Показать диапазон]
[Откалибровать заново]
```

## Поведение

Пользователь может:

* сразу начать упражнение;
* показать диапазон движения;
* откалибровать заново.

---

## Показать диапазон

Перед началом упражнения тренажёр может показать крайние положения грифа:

```text
Тренажёр покажет рабочий диапазон движения.

Гриф плавно переместится:
1. к нижней точке;
2. к верхней точке;
3. вернётся в стартовое положение.

Движение выполняется с низким моментом.
```

Кнопки:

```text
[Показать диапазон]
[Откалибровать заново]
[Начать упражнение]
```

---

# Вариант 2 — Калибровка не найдена

## Как отображать

Блок калибровки становится заметным.

```text
Диапазон движения

Калибровка не найдена

Перед началом упражнения необходимо задать нижнее и верхнее положения грифа.

[Откалибровать]
```

Кнопка `Начать упражнение` неактивна.

Подпись под кнопкой:

```text
Сначала выполните калибровку.
```

---

## После нажатия `Откалибровать`

Экран переходит в режим калибровки.

```text
Шаг 1. Установите нижнюю точку
[Запомнить нижнюю точку]

Шаг 2. Установите верхнюю точку
[Запомнить верхнюю точку]

[Проверить диапазон]
[Готово]
```

После завершения калибровки экран возвращается к обычной настройке упражнения.

---

# Вариант 3 — Калибровка не требуется

Для упражнений без управляемого грифа блок выглядит очень просто.

```text
Калибровка

Не требуется

Калибровка не требуется для упражнений с собственным весом.
```

Пример:

```text
Отжимания

Калибровка: не требуется
```

В этом варианте не показываются:

* нижняя точка;
* верхняя точка;
* положение грифа;
* управление приводами;
* диапазон движения.

---

# Блок 6 — Готовность к упражнению

## Назначение

Показывает, можно ли запускать упражнение.

---

## Для упражнения с тренажёром

```text
Готовность к упражнению

✓ Тренажёр готов
✓ Левый привод подключён
✓ Правый привод подключён
✓ Зона движения свободна
```

---

## Для упражнения без тренажёра

```text
Готовность к упражнению

✓ Зона движения свободна
✓ Поверхность устойчива
✓ Техника готова к показу
```

---

## Если есть проблема

```text
Запуск недоступен

Правый привод не подключён.
```

Кнопки:

```text
[Диагностика]
[Повторить проверку]
```

---

# Подтверждение зоны движения

Для упражнений с движением грифа нужно подтверждение:

```text
[✓ Зона движения свободна]
```

Без подтверждения кнопка `Начать упражнение` неактивна.

Для упражнений без тренажёра подтверждение можно сделать мягче:

```text
Зона движения свободна
```

---

# Основная кнопка

Внизу экрана находится главная кнопка:

```text
[Начать упражнение]
```

Кнопка должна быть:

* широкой;
* золотой;
* крупной;
* хорошо заметной;
* доступной только если нет критических блокировок.

---

# Кнопка назад

Внизу слева:

```text
[Назад]
```

Возвращает пользователя на предыдущий экран.

---

# Состояния кнопки `Начать упражнение`

## Активна

Если:

* упражнение выбрано;
* параметры заданы;
* тренажёр готов, если он нужен;
* калибровка есть или не требуется;
* зона движения подтверждена, если требуется.

---

## Неактивна

Если:

* калибровка обязательна, но не выполнена;
* тренажёр не готов;
* активна аварийная остановка;
* нет связи с приводом;
* не задана нагрузка;
* не подтверждена зона движения.

Пример подписи:

```text
Сначала выполните калибровку.
```

# Сохранённая калибровка

Если упражнение уже было откалибровано, должны подтягиваться сохранённые данные:

```ts
type ExerciseCalibration = {
  id: string;

  userId: string;
  exerciseId: string;

  lowerPositionMm: number;
  upperPositionMm: number;
  rangeMm: number;

  createdAt: string;
  updatedAt: string;
  lastUsedAt?: string;

  rangePreviewCompleted?: boolean;

```

---

# Поведение сохранённой калибровки

Если калибровка найдена:

```text
1. Подтянуть нижнюю и верхнюю точки.
2. Показать компактный блок “Диапазон движения”.
3. Дать кнопку “Показать диапазон”.
4. Дать кнопку “Откалибровать заново”.
5. Разрешить старт, если остальные проверки пройдены.
```

---

# Поведение отсутствующей калибровки

Если калибровки нет:

```text
1. Показать блок “Калибровка не найдена”.
2. Объяснить, что нужен диапазон движения.
3. Показать кнопку “Откалибровать”.
4. Заблокировать кнопку “Начать упражнение”.
```

---

# Поведение упражнений без калибровки

Если упражнение не требует калибровки:

```text
1. Не показывать технические данные грифа.
2. Не показывать нижнюю и верхнюю точку.
3. Показать “Калибровка не требуется”.
4. Разрешить старт после проверки базовой готовности.
```

# Ключевые требования

1. Экран называется **“Настройка упражнения”**.
2. Экран нужен прежде всего для настройки нагрузки и параметров выполнения.
3. Калибровка является дополнительным состоянием, а не главным смыслом экрана.
4. Если калибровка сохранена, её нужно показывать компактно.
5. Если калибровка не найдена, нужно показать заметный блок и заблокировать старт.
6. Если упражнение не требует калибровки, технические блоки калибровки не показываются.
7. Должна быть возможность откалибровать упражнение заново.
8. Должна быть возможность показать сохранённый диапазон перед стартом.
9. Показ диапазона выполняется с низким моментом двигателя.
10. Пользователь может менять вес, подходы, повторы, отдых и режим нагрузки.
11. Для упражнений с собственным весом показывается собственный вес вместо килограммов.
12. Для упражнений на время показывается время вместо повторов.
13. Если тренажёр не готов, старт блокируется.
14. Кнопка `СТОП` всегда видна.
15. Интерфейс должен быть крупным, понятным и удобным для 4K-монитора.
