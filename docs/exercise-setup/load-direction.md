# Направление нагрузки грифа

В настройке упражнения доступен отдельный выбор:

- **Нагрузка вниз** — прежний режим, выбран по умолчанию.
- **Тяга вверх** — нагрузка направлена вверх, пользователь тянет гриф вниз.

Направление не меняет стартовую точку: для тяги сверху выберите также верхнюю
стартовую точку и проверьте нижнюю/верхнюю границы амплитуды.
Выбор сохраняется для упражнения. Во время текущего подхода изменение относится
только к следующему подходу; пауза и продолжение сохраняют текущее направление.
Нагрузка нарастает и снимается плавно, верхняя граница защищается зеркально нижней.
Доступная тяга вверх меньше полной силы привода: часть силы удерживает сам гриф
и компенсирует трение. Система ограничивает запрос доступным запасом.

## Перед использованием

Схема БД требует миграции Alembic `20261016_0010`. Она добавляет направление
со значением `down` для прежних настроек. Миграция в рабочую БД в рамках этой
работы не выполнялась. Обновление и перезапуск выполняются только после
завершения подхода, установки грифа на механические упоры и исключения доступа
людей к зоне движения; затем проверяются оба направления с малой нагрузкой
по утверждённой процедуре пусконаладки.

Программная фиксация не является тормозом или страховкой человека.
На задержанном двойнике обнаружена сильная раскачка исходного фиксированного
удержания под постоянной нагрузкой; настройка коэффициентов, одновременно
улучшающая прогиб и резкое отпускание, пока не подтверждена. Не использовать
повисание человека как калибровочный груз. См. результаты в документе
[проверки удержания](../pre-start-check/fixed-hold-twin-validation.md).
