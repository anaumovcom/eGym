# Экран 15 — Итог тренировки

## Назначение экрана

Экран **“Итог тренировки”** появляется после завершения всей тренировки.

Он нужен, чтобы пользователь понял:

```text
Что я сегодня сделал?
Насколько хорошо прошла тренировка?
Какие мышцы нагрузил?
Есть ли прогресс?
Что Forma рекомендует дальше?
Когда лучше тренироваться снова?
```

Это финальный экран занятия. Он должен быть мотивирующим, понятным и не перегруженным.

---

# Главная задача экрана

Экран должен показать:

* общее время тренировки;
* выполненные упражнения;
* подходы и повторы;
* общий объём;
* качество выполнения;
* усталость мышц после тренировки;
* сравнение с прошлой похожей тренировкой;
* новые достижения;
* рекомендации на восстановление;
* план следующей тренировки;
* кнопку завершения.

---

# Общая структура экрана

Экран состоит из 8 основных зон:

| № | Блок                              | Назначение                                                |
| - | --------------------------------- | --------------------------------------------------------- |
| 1 | **Финальный статус**              | Тренировка завершена, краткая оценка.                     |
| 2 | **Главные метрики**               | Время, упражнения, подходы, объём, повторы.               |
| 3 | **Список выполненных упражнений** | Что было сделано по каждому упражнению.                   |
| 4 | **План vs факт**                  | Насколько тренировка совпала с планом.                    |
| 5 | **Карта нагрузки мышц**           | Какие мышцы получили нагрузку.                            |
| 6 | **Прогресс и достижения**         | Рекорды, улучшения, серия тренировок.                     |
| 7 | **Рекомендация Forma**            | Что делать дальше: отдых, следующая тренировка, нагрузка. |
| 8 | **Действия**                      | Завершить, открыть прогресс, повторить, запланировать.    |

---

# Верхняя системная панель

Панель остаётся единой для всего приложения.

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод подключён]
[Правый привод подключён]
[Безопасность включена]
[СТОП]
```

На этом экране кнопка `СТОП` уже не является основным действием, но всё равно остаётся видимой как часть системы безопасности.

# Главный финальный блок

## Хорошее состояние

```text
Отличная работа, Алексей!

Тренировка выполнена полностью.
Вы сделали 5 упражнений, 18 подходов и 164 повтора.
```

## Если тренировка частично выполнена

```text
Тренировка завершена частично

Выполнено 3 из 5 упражнений.
Результат сохранён, незавершённые упражнения можно перенести.
```

## Если тренировка была прервана

```text
Тренировка остановлена

Часть результата сохранена.
Можно открыть итог, повторить позже или завершить тренировку.
```

# Главные метрики тренировки

Это крупные карточки в верхней части.

```text
47 минут
длительность

5 / 5
упражнений

18 / 18
подходов

164
повтора

6 420 кг
общий объём
```

## Возможные метрики

| Метрика           | Пример                         |
| ----------------- | ------------------------------ |
| Длительность      | 47 минут                       |
| Упражнений        | 5 из 5                         |

# Блок “План vs факт”

Показывает, насколько тренировка совпала с планом.

```text
План

5 упражнений
18 подходов
≈45 минут
6 200 кг объём

Факт

5 упражнений
18 подходов
47 минут
6 420 кг объём

Итог:
+220 кг к плану
+2 минуты к расчётному времени
```

## Варианты результата

```text
План выполнен полностью
```

```text
Объём выше плана на 4%
```

```text
Выполнено на 2 подхода меньше плана
```

```text
Тренировка была короче на 8 минут
```

# Карта нагрузки мышц

Очень важный блок для твоего проекта.

После тренировки нужно показать, какие мышцы получили нагрузку.

## Пример

```text
Нагрузка мышц

Высокая:
спина, бицепс

Средняя:
предплечья, задняя дельта

Лёгкая:
кор

Почти не нагружались:
грудь, ноги, трицепс
```

## Визуально

Нужно показать SVG-человека:

```text
[Тело спереди] [Тело сзади]
```

Цвета:

| Цвет      | Значение               |
| --------- | ---------------------- |
| Зелёный   | лёгкая нагрузка        |
| Жёлтый    | средняя нагрузка       |
| Оранжевый | высокая нагрузка       |
| Красный   | очень высокая нагрузка |
| Серый     | не нагружалось         |

# Новая усталость после тренировки

После тренировки система должна обновить карту усталости.

```text
После тренировки

Спина: высокая усталость
Бицепс: высокая усталость
Предплечья: средняя усталость
Кор: лёгкая усталость
```

Можно добавить прогноз:

```text
Ожидаемое восстановление:
спина — около 48 часов
бицепс — около 36 часов
```

# Рекомендация Forma

Финальная рекомендация должна быть короткой и практичной.

## Пример хорошей тренировки

```text
Рекомендация Forma

Тренировка прошла хорошо.
Спина и бицепс получили высокую нагрузку.

Следующую тяжёлую тренировку на эти мышцы лучше поставить через 48 часов.
Завтра можно сделать ноги, лёгкий кор или день отдыха.
```

## Если тренировка была тяжёлая

```text
Рекомендация Forma

Тренировка была тяжёлой.
В последних подходах темп и амплитуда немного снизились.

На следующей тренировке лучше оставить веса без увеличения
или добавить больше отдыха между подходами.
```

## Если тренировка была лёгкая

```text
Рекомендация Forma

Тренировка прошла легко.
В следующий раз можно немного увеличить вес или добавить один подход.
```

# Субъективная оценка всей тренировки

В конце можно спросить:

```text
Как прошла тренировка?

[Легко] [Нормально] [Тяжело]
```

И отдельно:

```text
Был дискомфорт?

[Нет] [Небольшой] [Лучше снизить нагрузку]
```

Эти данные помогут корректировать будущие рекомендации.

# Фото прогресса после тренировки

Основной сценарий фото — **перед тренировкой**, но после тренировки можно аккуратно предложить фото только если пользователь включил такую опцию.

По умолчанию на этом экране не нужно делать фото-блок главным.

Возможный мягкий блок:

```text
Фото прогресса

Следующее фото рекомендуется через 7 дней.
```

Без кнопки, если не нужно.

# Сохранение результата

Результат тренировки должен сохраняться автоматически при завершении.

Внизу можно показать:

```text
Результат сохранён в профиль Алексея
```

Если что-то не сохранилось:

```text
Не удалось сохранить результат

[Повторить сохранение]
[Экспортировать вручную]
```

# Ключевые требования

1. Экран появляется после завершения всей тренировки.
2. Экран должен быть мотивирующим и спокойным.
3. Нужно показать главные метрики тренировки.
4. Нужно показать список выполненных упражнений.
5. Нужно показать план vs факт.
6. Нужно показать нагрузку мышц на SVG-карте.
7. Нужно показать обновлённую усталость мышц после тренировки.
8. Нужно показать прогресс и достижения.
9. Нужно показать рекомендацию Forma.
10. Нужно показать следующую тренировку, если она запланирована.
11. Результат должен сохраняться автоматически.
12. Если сохранение не удалось, нужно показать ошибку и повторить сохранение.
13. Пользователь может оценить тренировку: легко / нормально / тяжело.
14. Пользователь может отметить дискомфорт.
15. Если тренировка выполнена частично, это должно быть явно видно.
16. Если тренировка была прервана ошибкой, это должно быть явно видно.
17. Главные действия: на главную, открыть прогресс, открыть календарь, повторить.
18. Экран должен быть удобен для большого 4K-монитора.
