# Общие правила интерфейса и навигации Forma

## Назначение документа

Этот документ фиксирует общие правила, которые должны использоваться во всех экранах Forma.

Он нужен, чтобы отдельные экранные документы не расходились в:

* названии пунктов меню;
* составе верхней системной панели;
* порядке пользовательских сценариев;
* терминах безопасности;
* переходах между основными и промежуточными экранами.

---

# Название приложения

```text
Forma
```

Название должно использоваться одинаково во всех экранах, верхних панелях, заголовках и сообщениях.

---

# Каноническая верхняя системная панель

Для основных экранов после выбора пользователя:

```text
Forma  [Алексей]  [Тренажёр готов]  [Левый привод: подключён]  [Правый привод: подключён]  [Безопасность включена]  [СТОП]
```

Для экрана выбора пользователя активный профиль ещё не выбран, поэтому пользователь не показывается:

```text
Forma  [Тренажёр готов]  [Левый привод: подключён]  [Правый привод: подключён]  [Безопасность включена]  [СТОП]
```

Для live-экрана выполнения упражнения панель может быть компактнее, но `СТОП` всегда остаётся самым заметным элементом.

---

# Термины верхней панели

| Термин | Использовать | Не использовать |
| ------ | ------------ | --------------- |
| Система безопасности | `Безопасность включена` | `Защита активна`, `Защита` |
| Левый привод | `Левый привод: подключён` | разные сокращения без необходимости |
| Правый привод | `Правый привод: подключён` | разные сокращения без необходимости |
| Аварийная остановка | `СТОП` | `Stop`, `Emergency`, мелкие варианты |

# Разделение ответственности экранов

| Экран | Отвечает за | Не отвечает за |
| ----- | ----------- | -------------- |
| Главная | что делать сегодня и почему | детальную настройку упражнения |
| Быстрый старт | быстрый выбор упражнения и параметров | полный каталог и глубокую аналитику |
| Сегодня | выполнение плана на сегодня | создание программы с нуля |
| Календарь | планирование по дням | выполнение подхода |
| Конструктор | структура программы | live-выполнение упражнения |
| Программы | выбор готового шаблона | ручную сборку с нуля |
| Каталог | поиск и просмотр базы упражнений | боковую панель полного планирования |
| Карточка упражнения | подробности упражнения | выполнение подхода |
| Настройка упражнения | вес, подходы, повторы, калибровка | диагностику тренажёра в полном виде |
| Выполнение упражнения | live-подход | редактирование программы |
| Профиль | личные данные и цели | безопасность механики |
| Настройки системы | тренажёр и безопасность | цели и фото пользователя |

# Фото прогресса

Единое правило:

```text
Фото прогресса не показывается отдельным блоком на главной, календаре, быстром старте или библиотеке программ.
```

Оно открывается как отдельный экран:

```text
Фотофиксация прогресса
```

Профиль и прогресс могут показывать уже сохранённые фото и запускать новую фотофиксацию вручную.

---

# Проверка необходимости фото прогресса

`Проверка необходимости фото прогресса` — это логический шаг, а не отдельный экран.

Система проверяет в фоне:

* дату последней фотофиксации;
* настройки напоминаний пользователя;
* контрольные даты программы;
* источник запуска: тренировка, быстрый старт, программа или ручное действие.

Если фото требуется:

```text
Проверка необходимости фото прогресса
→ Фотофиксация прогресса
→ Настройка упражнения
```

Если фото не требуется:

```text
Проверка необходимости фото прогресса
→ Настройка упражнения
```

Пользователь не должен видеть отдельный промежуточный экран проверки.

# Модальные окна и панели

Клик по элементу не всегда должен вести на новый экран.

Единые правила:

```text
Клик по мышце → MuscleDetailsPanel

Клик по дню календаря → DayDetailsPanel
```

# Термины калибровки и лимитов

```text
Глобальные лимиты движения = системные ограничения тренажёра.
Калибровка упражнения = диапазон конкретного упражнения для конкретного пользователя.
Показ диапазона = безопасная демонстрация сохранённого диапазона с низкой скоростью и низким моментом.
```

Эти понятия нельзя смешивать в интерфейсе и документации.

# Ключевые требования

1. Во всех основных экранах использовать единое меню.
2. В верхней панели использовать термин `Безопасность включена`.
3. Кнопка `СТОП` всегда видна.
4. Фото прогресса — отдельный промежуточный экран.
5. После проверки фото прогресса открывается экран настройки упражнения.
6. Профиль пользователя не содержит инженерных настроек тренажёра.
7. Настройки системы не содержат целей, фото и истории прогресса пользователя.
8. Калибровка упражнения не равна глобальным лимитам движения.
9. Упражнения из чёрного списка не участвуют в автогенерации, но доступны вручную с предупреждением.
10. Все экраны должны быть рассчитаны на большой 4K-монитор и сенсорное управление.
11. Повторяющиеся элементы должны использовать компоненты из `docs/common/ui-components.md`.
12. Модальные окна, панели и оверлеи должны соответствовать `docs/common/modals-panels-overlays.md`.
