# Модальные окна, панели и оверлеи Forma

## Назначение документа

Этот документ описывает единые правила для модальных окон, правых панелей, подтверждений, всплывающих меню, уведомлений и аварийных оверлеев.

Он нужен, чтобы клики по элементам на разных экранах открывали предсказуемые и одинаково устроенные интерфейсы.

---

# Главное правило

Не каждый клик должен открывать новый экран.

В Forma используются разные типы поверхностей:

| Тип | Когда использовать |
| --- | ------------------ |
| `Modal` | Нужно сфокусировать пользователя на отдельной задаче |
| `SidePanel` | Нужно показать детали выбранного элемента, сохранив контекст экрана |
| `ConfirmDialog` | Нужно подтвердить опасное или необратимое действие |
| `ActionSheet` | Нужно выбрать одно действие из короткого списка |
| `Popover` | Небольшая справка или настройки рядом с элементом |
| `Toast` | Короткое сообщение об успехе, ошибке или предупреждении |
| `BlockingOverlay` | Действие заблокировано и требует внимания |
| `EmergencyStopOverlay` | Аварийная остановка активна |

---

# Базовые правила поведения

1. `СТОП` остаётся доступным поверх любых модальных окон и панелей.
2. Модальное окно не должно скрывать критические статусы безопасности.
3. Закрытие модального окна возвращает пользователя на тот же экран и сохраняет контекст.
4. Опасные действия требуют `ConfirmDialog`.
5. Ошибки запуска или движения показываются как `BlockingOverlay` или `BlockingAlert`.
6. Короткие успешные действия показываются через `Toast`.
7. Правые панели используются для деталей выбранного элемента на больших 4K-экранах.
8. Модальные окна не должны заменять полноценные экраны, если задача сложная или длительная.

---

# 1. `Modal`

## Назначение

`Modal` используется для отдельной задачи, которая временно блокирует взаимодействие с фоном.

## Примеры

* подробности упражнения в каталоге;
* добавление тренировки в день календаря;
* выбор программы;
* замена упражнения;
* настройка режима нагрузки;
* подтверждение переноса тренировки;
* выбор даты.

## Структура

```text
Заголовок
Краткое объяснение
Основной контент
Основные действия
Вторичные действия
Закрыть
```

## Правила размера для 4K

| Размер | Когда использовать |
| ------ | ------------------ |
| `small` | подтверждение, короткая настройка |
| `medium` | выбор даты, режим нагрузки, фильтр |
| `large` | подробности упражнения, замена упражнения |
| `fullscreen` | только если задача почти равна экрану |

---

# 2. `SidePanel`

## Назначение

`SidePanel` используется для деталей выбранного элемента без потери контекста основного экрана.

## Где использовать

| Экран | Что открывает панель |
| ----- | -------------------- |
| Календарь | выбранный день |
| Библиотека программ | выбранная программа |
| Сегодняшняя тренировка | выбранное упражнение |
| Конструктор | выбранное упражнение или группа |
| Усталость | выбранная мышца |
| Прогресс | выбранное упражнение / период |

## Структура

```text
Заголовок панели
Выбранный объект
Ключевые параметры
Контекстные предупреждения
Основные действия
Вторичные действия
```

## Правила

1. Панель не должна закрывать левое меню.
2. Панель может иметь собственный скролл.
3. Основной список сохраняет позицию скролла.
4. Повторный клик по другому элементу обновляет содержимое панели.
5. Кнопка закрытия возвращает экран в состояние без выбранного элемента.

---

# 3. `ConfirmDialog`

## Назначение

Подтверждение опасного или необратимого действия.

## Когда обязательно

```text
Удалить тренировку из календаря
Удалить упражнение из программы
Очистить чёрный список
Удалить фото прогресса
Сбросить настройки
Удалить калибровку
Переустановить нулевую позицию
Войти в инженерный режим
Перенести тренировку с возможным перегрузом
```

## Шаблон

```text
Заголовок действия

Что произойдёт после подтверждения.
Почему это может быть важно.

[Отменить]
[Подтвердить]
```

Для опасного действия подтверждающая кнопка должна быть визуально опасной, но не похожей на `СТОП`.

---

# 4. `ActionSheet`

## Назначение

Короткий список действий по выбранному объекту.

## Пример для упражнения

```text
Тяга сверху

[Начать]
[Открыть подробно]
[Заменить]
[Добавить в избранное]
[В чёрный список]
```

## Пример для дня календаря

```text
Пятница, 17 мая

[Открыть день]
[Добавить тренировку]
[Сгенерировать тренировку]
[Оставить отдых]
```

---

# 5. `Popover`

## Назначение

Небольшая подсказка или настройка рядом с элементом.

## Примеры

* объяснение готовности `78%`;
* подсказка по статусу мышцы;
* расшифровка режима нагрузки;
* объяснение предупреждения;
* подсказка по калибровке.

## Правило

`Popover` должен быть коротким. Если нужно больше текста или действий, использовать `SidePanel` или `Modal`.

---

# 6. `Toast`

## Назначение

Короткое сообщение, которое не требует немедленного решения.

## Типы

| Тип | Пример |
| --- | ------ |
| `success` | `Программа сохранена` |
| `info` | `Калибровка будет выполнена перед упражнением` |
| `warning` | `Грудь имеет среднюю усталость` |
| `error` | `Не удалось загрузить видео` |

## Правила

1. Не использовать для критических блокировок.
2. Не закрывать кнопку `СТОП`.
3. Для ошибок, требующих действий, использовать `BlockingAlert`.

---

# 7. `BlockingOverlay`

## Назначение

Показывает состояние, при котором продолжать нельзя.

## Примеры

```text
Запуск заблокирован
Правый привод не подключён.

[Открыть диагностику]
[Повторить проверку]
[Назад]
```

```text
Калибровка не найдена
Перед началом упражнения нужно задать нижнюю и верхнюю точки.

[Откалибровать]
[Назад]
```

---

# 8. `EmergencyStopOverlay`

## Назначение

Появляется после нажатия `СТОП`.

## Текст

```text
Аварийная остановка активна

Движение приводов заблокировано.
Проверьте зону движения и состояние тренажёра.

[Открыть диагностику]
[Завершить упражнение]
[Разблокировать систему]
```

## Правила

1. Поверх всех экранов и модальных окон.
2. Не закрывается обычным кликом вне окна.
3. Разблокировка требует явного действия и, при необходимости, PIN.
4. Если упражнение выполнялось, результат можно сохранить как неполный.

# Карта кликов по элементам

| Элемент | Где | Что открывается |
| ------- | --- | --------------- |
| Мышца на карте | Главная, Усталость, Прогресс, Карточка упражнения | `MuscleDetailsPanel` |
| Карточка упражнения | Каталог | `ExerciseDetailsModal` |
| Строка упражнения | Сегодня | `ExerciseDetailsPanel` |
| Упражнение в конструкторе | Конструктор | `ExerciseEditPanel` |
| Карточка программы | Библиотека программ | `ProgramDetailsPanel` |
| День календаря | Календарь | `DayDetailsPanel` |
| Предупреждение | Любой экран | `WarningDetailsPopover` или `WarningDetailsPanel` |
| `Удалить` | Календарь, конструктор, профиль | `ConfirmDialog` |
| `Заменить упражнение` | Сегодня, конструктор | `ExerciseReplacementModal` |
| `Перенести` | Календарь | `RescheduleWorkoutModal` |
| `Добавить тренировку` | Календарь | `AddWorkoutModal` |
| `Изменить режим нагрузки` | Быстрый старт, настройка упражнения | `LoadModeModal` |
| `Показать диапазон` | Настройка упражнения | `RangePreviewDialog` |
| `СТОП` | Любой экран | `EmergencyStopOverlay` |

# Основные модальные окна Forma

## `ExerciseDetailsModal`

Открывается в каталоге и быстрых списках.

Содержит:

```text
Название упражнения
Видео 16:9
Мышцы
Краткая техника
Совместимость сегодня
Последний результат
Действия: Начать / Добавить / Открыть подробно / В избранное / В чёрный список
```

---

## `ExerciseReplacementModal`

Открывается при замене упражнения.

Содержит:

```text
Текущее упражнение
Причина замены
Рекомендуемые замены
Фильтры по мышцам / оборудованию / усталости
Предупреждение о чёрном списке
```

Действия:

```text
[Заменить]
[Открыть карточку]
[Отмена]
```

---

## `AddWorkoutModal`

Открывается из календаря.

Содержит:

```text
Дата
Варианты добавления:
- Сгенерировать по целям
- Выбрать из библиотеки
- Выбрать мою программу
- Создать новую
- Повторить последнюю
```

---

## `RescheduleWorkoutModal`

Открывается при переносе тренировки.

Содержит:

```text
Текущая дата
Новая дата
Предупреждение о перегрузе мышц
Варианты: завтра / выбрать дату / поменять местами / сдвинуть неделю
```

Если перенос создаёт перегруз, нужно показать `WarningBanner` внутри модального окна.

---

## `LoadModeModal`

Открывается при изменении режима нагрузки.

Содержит:

```text
Обычный вес
Помощь вверх
Негативная фаза
Лёгкий режим
```

Для каждого режима нужно показать короткое объяснение и влияние на безопасность.

---

## `RangePreviewDialog`

Открывается перед показом сохранённого диапазона.

Содержит:

```text
Тренажёр плавно покажет нижнюю и верхнюю точки диапазона.
Движение выполняется с низкой скоростью и низким моментом.

[Показать диапазон]
[Отмена]
```

Требует подтверждения свободной зоны движения.

---

# Правила закрытия

| Поверхность | Как закрывается |
| ----------- | --------------- |
| `Modal` | `Закрыть`, `Отмена`, Esc, клик вне окна если нет несохранённых изменений |
| `SidePanel` | `Закрыть`, повторный выбор, переход на другой экран |
| `ConfirmDialog` | Только `Отмена` или подтверждение |
| `EmergencyStopOverlay` | Только безопасная разблокировка или переход в диагностику |
| `Toast` | Автоматически или вручную |
| `Popover` | Клик вне подсказки или выбор действия |

Если есть несохранённые изменения, закрытие должно показывать `ConfirmDialog`.

---

# Состояния загрузки

Для модальных окон и панелей нужны единые состояния:

```text
loading
loaded
empty
error
blocked
```

Пример ошибки:

```text
Не удалось загрузить данные

Проверьте локальную базу или повторите попытку.

[Повторить]
[Закрыть]
```

---

# Ключевые требования

1. `Modal`, `SidePanel`, `Popover`, `Toast` и `ConfirmDialog` должны быть разными компонентами.
2. Клик по карточке не всегда означает переход на новый экран.
3. Детали выбранного объекта чаще открываются в правой панели.
4. Опасные действия всегда требуют подтверждения.
5. Аварийная остановка всегда поверх остальных окон.
6. Все окна должны быть крупными и удобными для сенсорного управления.
7. Закрытие окна должно возвращать пользователя в исходный контекст.
8. Несохранённые изменения нельзя терять без подтверждения.
