# Термины Forma

## Назначение документа

Этот документ фиксирует единые термины для документации и интерфейса Forma.

Если термин встречается на нескольких экранах, нужно использовать формулировку из этого словаря.

---

# Основные термины

| Термин | Значение | Не использовать как замену |
| ------ | -------- | -------------------------- |
| `Forma` | Название приложения | другие названия приложения |
| `СТОП` | Аварийная остановка | Stop, Emergency, аварийная кнопка без названия |
| `Безопасность включена` | Система безопасности активна | Защита активна, Защита |
| `Тренажёр готов` | Система разрешает старт при выполнении условий упражнения | Машина готова, устройство готово |
| `Левый привод: подключён` | Статус левого привода | левый мотор, левая сторона без контекста |
| `Правый привод: подключён` | Статус правого привода | правый мотор, правая сторона без контекста |

---

# Пользователь и профиль

| Термин | Значение |
| ------ | -------- |
| `Профиль пользователя` | Личные данные, цели, тело, фото, чёрный список |
| `Гость` | Разовый режим без сохранения прогресса |
| `Готовность` | Процентная оценка готовности пользователя к нагрузке |
| `Фото прогресса` | Сохранённые фото пользователя по датам |
| `Фотофиксация прогресса` | Процесс создания новых фото прогресса |
| `Чёрный список упражнений` | Упражнения, которые не предлагаются автоматически, но доступны вручную |

---

# Тренировки и программы

| Термин | Значение |
| ------ | -------- |
| `Тренировка` | Конкретный набор упражнений для выполнения |
| `Программа` | Шаблон или план тренировок, который можно сохранить или назначить |
| `Сегодняшняя тренировка` | Тренировка, запланированная на текущий день |
| `Быстрый старт` | Сценарий запуска одного упражнения без сборки полной программы |
| `Конструктор` | Экран создания и редактирования структуры программы |
| `Библиотека готовых программ` | Экран выбора готовых тренировок и планов |
| `Итог тренировки` | Экран после завершения всей тренировки |
| `Завершение упражнения` | Экран после завершения одного упражнения |

---

# Упражнения

| Термин | Значение |
| ------ | -------- |
| `Настройка упражнения` | Экран перед выполнением: вес, подходы, повторы, отдых, режим нагрузки, калибровка |
| `Выполнение упражнения` | Live-экран подхода |
| `Подход` | Один рабочий набор повторов или времени |
| `Повтор` | Один цикл движения |
| `Отдых между подходами` | Экран восстановления после подхода |
| `Режим нагрузки` | Способ создания нагрузки тренажёром |
| `Обычный вес` | Базовый режим сопротивления |
| `Помощь вверх` | Режим, где тренажёр помогает в подъёме |
| `Негативная фаза` | Акцент на контролируемом опускании |
| `Лёгкий режим` | Упрощённый режим с меньшей нагрузкой |

---

# Калибровка и движение

| Термин | Значение |
| ------ | -------- |
| `Калибровка упражнения` | Настройка нижней и верхней точки конкретного упражнения для пользователя |
| `Диапазон движения` | Сохранённые нижняя и верхняя точки упражнения |
| `Показ диапазона` | Безопасная демонстрация сохранённого диапазона с низкой скоростью и низким моментом |
| `Глобальные лимиты движения` | Системные ограничения тренажёра, не равные калибровке упражнения |
| `Нулевая позиция` | Системная точка отсчёта механики |
| `Рассинхрон сторон` | Разница позиции левой и правой стороны |
| `Синхронность сторон` | Статус согласованности движения левой и правой стороны |

---

# Мышцы и аналитика

| Термин | Значение |
| ------ | -------- |
| `Усталость мышц` | Текущее состояние восстановления мышечных групп |
| `fatigueScore` | Числовая усталость мышцы: `0` — нет усталости, `100` — очень высокая усталость, `100+` — перегруз |
| `Карта мышц` | Визуальная карта тела с подсветкой мышц |
| `MuscleMap` | Универсальный компонент карты мышц |
| `Готова` | Мышцу можно нагружать |
| `Лёгкая усталость` | Можно тренировать умеренно |
| `Средняя усталость` | Лучше снизить нагрузку |
| `Высокая усталость` | Лучше не нагружать |
| `Нагрузка за период` | Объём нагрузки на мышцы за выбранный период |

# Модальные элементы

| Термин | Значение |
| ------ | -------- |
| `Modal` | Модальное окно для отдельной задачи |
| `SidePanel` | Правая или боковая панель деталей без ухода со страницы |
| `ConfirmDialog` | Подтверждение опасного действия |
| `Toast` | Короткое уведомление |
| `Popover` | Маленькая подсказка рядом с элементом |
| `BlockingOverlay` | Блокирующее состояние, требующее действия |
| `EmergencyStopOverlay` | Оверлей после нажатия `СТОП` |

---

# Единые формулировки действий

| Использовать | Не использовать |
| ------------ | ---------------- |
| `Начать упражнение` | Запустить упражнение, стартовать упражнение |
| `Начать тренировку` | Запустить тренировку |
| `Завершить подход` | Закончить подход |
| `Завершить упражнение` | Закончить упражнение |
| `Открыть диагностику` | Перейти в диагностику, показать диагностику |
| `Откалибровать` | Настроить амплитуду, выставить точки без контекста |
| `Показать диапазон` | Показать амплитуду, проверить движение |
| `Сохранить и продолжить` | Далее, ОК без смысла |

---

# Ключевые требования

1. В интерфейсе использовать русские термины из этого словаря.
2. В технических типах можно использовать английские имена, но UI должен оставаться русским.
3. `Фото прогресса` — данные и галерея, `Фотофиксация прогресса` — процесс съёмки.
4. `Калибровка упражнения` не равна глобальным лимитам.
5. `СТОП` не заменять другими словами.
