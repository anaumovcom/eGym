# Экран 8 — Библиотека готовых программ

## Назначение экрана

Экран **“Библиотека готовых программ”** нужен, чтобы пользователь мог быстро выбрать готовую тренировку или тренировочный план, не собирая всё вручную в конструкторе.

Главная задача:

```text
Выбрать готовую программу → посмотреть состав → адаптировать под себя → сохранить или назначить в календарь
```

Это экран не для выполнения упражнения.
Это экран выбора и подготовки готового шаблона.

---

# Главное отличие от конструктора

```text
Библиотека готовых программ = выбрать уже готовую тренировку или план.
Конструктор = собрать свою тренировку вручную.
Календарь = назначить тренировку на конкретный день.
Сегодняшняя тренировка = выполнить тренировку сегодня.
```

---

# Что должно быть в библиотеке

Библиотека должна содержать разные типы программ:

```text
Разовая тренировка
Недельный план
Программа на 4 недели
Программа под цель
Восстановительная программа
Программа для новичка
Программа с чередованием упражнений
Силовая программа
Фуллбоди
Верх / низ
Push / Pull / Legs
```

---

# Основные сценарии

## Сценарий 1 — Выбрать готовую тренировку

```text
Библиотека
→ Выбрать программу “Спина + бицепс”
→ Открыть детали
→ Проверить упражнения
→ Сохранить в мои программы
→ Назначить в календарь
```

---

## Сценарий 2 — Запустить готовую тренировку сразу

```text
Библиотека
→ Выбрать программу
→ Открыть детали
→ Начать сегодня
→ Проверка фото прогресса, если нужно
→ Предстартовая проверка
→ Первое упражнение
```

---

## Сценарий 3 — Адаптировать под себя

```text
Библиотека
→ Выбрать программу
→ Адаптировать под меня
→ Forma учитывает уровень, цели, усталость и чёрный список
→ Открыть в конструкторе
→ Сохранить
```

---

## Сценарий 4 — Назначить план на неделю

```text
Библиотека
→ Выбрать недельный план
→ Посмотреть дни
→ Назначить в календарь
→ Выбрать дату начала
→ Подтвердить расписание
```

# Карточка программы

Каждая программа отображается как крупная карточка.

## Содержимое карточки

```text
Спина + бицепс

Силовая тренировка
5 упражнений
18 подходов
≈45 минут

Мышцы:
спина, бицепс, предплечья

Уровень:
средний

Совместимость:
хорошо подходит сегодня

[Открыть]
```

---

## Визуальные элементы карточки

На карточке можно показывать:

* название;
* иконку или мини-изображение;
* тип программы;
* длительность;
* количество упражнений;
* основные мышцы;
* уровень сложности;
* совместимость с текущим пользователем;
* метку “рекомендуется”;
* метку “есть чередование”;
* метку “можно сегодня”.

Когда пользователь выбирает карточку программы, справа открывается подробная панель.

```text
Основные мышцы:

хорошо подходит сегодня

[Начать сегодня]
[Адаптировать под меня]
[Сохранить в мои программы]
[Назначить в календарь]
[Открыть в конструкторе]
```

# Детальный состав программы

В правой панели или в отдельном модальном окне нужно показывать список упражнений.

## Пример

```text
Состав программы

1. Тяга сверху
   45 кг · 3×10 · отдых 90 сек

2. Тяга к поясу
   40 кг · 4×12 · отдых 90 сек

3. Тяга прямыми руками
   25 кг · 3×12 · отдых 75 сек

4. Сгибание рук
   20 кг · 3×12 · отдых 75 сек

5. Планка
   3×45 сек · отдых 45 сек
```

# Если программа содержит группу чередования

Нужно показывать её понятно.

## Пример

```text
Группа чередования:
Подтягивания + Присед

Круг 1:
Подтягивания ×10
Присед ×8

Круг 2:
Подтягивания ×8
Присед ×6

Круг 3:
Подтягивания ×6
Присед ×6
```

# Совместимость программы с пользователем

Очень важный блок.

Forma должна показать, насколько программа подходит текущему пользователю.

## Что учитывать

```text
цель пользователя;
уровень подготовки;
усталость мышц;
чёрный список упражнений;
доступное оборудование;
последние тренировки;
длительность;
рабочие веса.
```

---

## Пример совместимости

```text
Совместимость

Хорошо подходит сегодня

Почему:
спина готова к нагрузке,
бицепс имеет лёгкую усталость,
грудь и трицепс почти не нагружаются.
```

---

## Возможные состояния

| Статус                       | Значение                                                        |
| ---------------------------- | --------------------------------------------------------------- |
| **Отлично подходит**         | Можно ставить без изменений.                                    |
| **Подходит**                 | Можно использовать, возможно с небольшой адаптацией.            |
| **Нужна адаптация**          | Стоит снизить объём или заменить упражнения.                    |
| **Не рекомендуется сегодня** | Лучше выбрать другую программу или перенести.                   |
| **Есть конфликт**            | Есть упражнения из чёрного списка или недоступное оборудование. |

# Блок предупреждений

## Пример

```text
Предупреждения

Грудь имеет высокую усталость.
В этой программе грудь почти не нагружается — всё хорошо.

Упражнений из чёрного списка нет.

Оборудование доступно.
```

---

## Возможные предупреждения

```text
есть упражнение из чёрного списка;
программа слишком тяжёлая для сегодняшнего дня;
не хватает оборудования;
нагружается уставшая мышца;
длительность выше желаемой;
уровень сложности выше профиля пользователя.
```

# Кнопка “Адаптировать под меня”

Одна из самых важных функций.

## Назначение

При нажатии Forma автоматически изменяет программу под пользователя.

Учитываются:

```text
уровень подготовки;
рабочие веса;
усталость мышц;
чёрный список;
предпочтительная длительность;
цели;
последние результаты.
```

---

## Что может измениться

```text
рабочие веса;
количество подходов;
количество повторов;
отдых;
замена упражнения;
исключение упражнения из чёрного списка;
сокращение длительности;
облегчение нагрузки на уставшие мышцы.
```

---

## Пример

Было:

```text
Жим лёжа
50 кг · 4×10
```

После адаптации:

```text
Жим лёжа
40 кг · 3×10

Причина:
грудь сегодня имеет высокую усталость.
```

---

# Кнопка “Открыть в конструкторе”

Если пользователь хочет вручную изменить программу:

```text
Открыть в конструкторе
```

Переход:

```text
Библиотека программ
→ Конструктор тренировок
→ Программа открыта как копия
```

Важно: готовый шаблон из библиотеки лучше не редактировать напрямую.
Нужно создавать копию:

```text
Создана копия программы “Спина + бицепс”.
```

---

# Кнопка “Сохранить в мои программы”

Назначение:

```text
Добавить выбранную программу в личную библиотеку пользователя.
```

После нажатия:

```text
Программа сохранена в “Мои программы”.

[Назначить в календарь]
[Открыть в конструкторе]
[Остаться в библиотеке]
```

---

# Кнопка “Назначить в календарь”

Назначает программу на дату.

## Сценарий

```text
Библиотека программ
→ Назначить в календарь
→ Выбрать дату
→ Выбрать повторение, если нужно
→ Сохранить
```

---

# Кнопка “Начать сегодня”

Позволяет сразу выполнить программу.

## Сценарий

```text
Библиотека программ
→ Начать сегодня
→ Проверка необходимости фото прогресса
→ Предстартовая проверка
→ Первое упражнение
```

Если программа не адаптирована, можно сначала показать:

```text
Адаптировать программу под вас перед стартом?
```

Кнопки:

```text
[Адаптировать]
[Начать как есть]
[Открыть в конструкторе]
```

# Состояния экрана

## 1. Программы загружены

```text
Выберите готовую программу
или воспользуйтесь рекомендациями Forma.
```

---

## 2. Ничего не найдено

```text
Ничего не найдено

Попробуйте изменить фильтры
или создать программу вручную.
```

Кнопки:

```text
[Сбросить фильтры]
[Создать в конструкторе]
```

---

## 3. Программа выбрана

```text
Спина + бицепс выбрана

Можно сохранить, адаптировать или назначить в календарь.
```

---

## 4. Есть конфликт

```text
Программа требует адаптации

Причина:
одно упражнение находится в чёрном списке пользователя.
```

Кнопки:

```text
[Адаптировать]
[Открыть в конструкторе]
[Выбрать другую]
```

---

## 5. Тренажёр не готов

Библиотеку можно просматривать, но запуск программы недоступен.

```text
Тренажёр не готов

Можно сохранить программу или назначить её в календарь,
но начать тренировку сейчас нельзя.
```

Кнопка `Начать сегодня` должна быть заблокирована.

# Детальная компоновка экрана

## Левая часть

* поиск;
* фильтры;
* категории;
* сетка карточек программ.

## Правая часть

* выбранная программа;
* список упражнений;
* совместимость;
* предупреждения;
* основные действия.

## Нижняя часть

* дополнительные категории;
* популярные программы;
* недавно использованные;
* мои сохранённые.

# Работа с фото прогресса

На экране библиотеки не показываем блок фото прогресса.

Проверка происходит только при старте:

```text
Библиотека
→ Начать сегодня
→ Проверка необходимости фото прогресса
→ Фотофиксация, если нужна
→ Предстартовая проверка
```

---

# Работа с чёрным списком

Правило:

```text
Готовая программа может содержать упражнение,
которое находится в чёрном списке пользователя.

В таком случае Forma должна показать конфликт
и предложить адаптацию.
```

Пример:

```text
В программе есть упражнение из чёрного списка:
Жим из-за головы.

Рекомендуется заменить его перед сохранением.
```

Кнопки:

```text
[Адаптировать]
[Открыть в конструкторе]
[Выбрать другую]
```

# Работа с усталостью

Если программа нагружает уставшие мышцы:

```text
Сегодня программа не рекомендуется

Причина:
грудь и трицепс имеют высокую усталость.

Можно:
- адаптировать программу;
- перенести на другой день;
- выбрать восстановительную тренировку.
```

---

# Работа с тренажёром

Если тренажёр не готов:

* библиотеку можно смотреть;
* программы можно сохранять;
* программы можно назначать в календарь;
* запускать тренировку нельзя.

Сообщение:

```text
Тренажёр не готов

Начать сегодня нельзя,
но программу можно сохранить или назначить в календарь.
```

# Состояния кнопок

## Начать сегодня

Активна, если:

```text
тренажёр готов;
нет критического конфликта;
программа может быть выполнена сегодня.
```

Заблокирована, если:

```text
тренажёр не готов;
аварийная остановка активна;
есть критический конфликт;
программа не адаптирована при обязательном конфликте.
```

# Ключевые требования

1. Экран рассчитан на большой 4K-монитор.
2. Экран должен выглядеть как премиальная библиотека шаблонов.
3. Пользователь должен быстро находить подходящую программу.
4. Должны быть фильтры по цели, длительности, уровню и оборудованию.
5. Должны быть категории программ.
6. Каждая программа должна иметь понятную карточку.
7. Правая панель должна показывать состав и совместимость программы.
8. Должна быть кнопка `Адаптировать под меня`.
9. Должна быть кнопка `Сохранить в мои программы`.
10. Должна быть кнопка `Назначить в календарь`.
11. Должна быть кнопка `Открыть в конструкторе`.
12. Можно начинать программу сегодня, если тренажёр готов.
13. Фото прогресса не показывается на этом экране.
14. Фото прогресса проверяется только при старте.
15. Чёрный список упражнений должен учитываться при проверке программы.
16. Усталость мышц должна учитываться при рекомендации программы.
17. Библиотека не должна заменять конструктор.
18. Готовые шаблоны лучше редактировать через копию.
19. Программы могут быть разовыми, недельными или много-недельными.
20. Интерфейс должен быть крупным, тёмным, красивым и удобным для сенсорного управления.
