# Экран 9 — Каталог упражнений

## Назначение экрана

Экран **“Каталог упражнений”** в приложении **Forma** нужен для просмотра всей локальной базы упражнений.

Пользователь должен иметь возможность:

- быстро найти упражнение;
- отфильтровать упражнения по мышцам, оборудованию и сложности;
- посмотреть видео-превью;
- открыть подробности упражнения в модальном окне;
- начать упражнение;
- добавить упражнение в тренировку;
- добавить упражнение в избранное;
- добавить упражнение в чёрный список.

---

# Источник данных

Все упражнения находятся локально в папке проекта:

```text
/exercises
```

Для каждого упражнения создаётся отдельная папка:

```text
/exercises/barbell-floor-press/
  exercise.json
  male-Barbell-barbell-floor-press-side.mp4
  male-Barbell-barbell-floor-press-front.mp4
  female-Barbell-barbell-floor-press-front.mp4
  female-Barbell-barbell-floor-press-side.mp4
```

В каждой папке находятся:

* `json`-файл с данными упражнения;
* видеофайлы упражнения;
* при необходимости позже — постеры, превью, дополнительные медиа.

# Главное правило экрана

```text
Каталог упражнений = поиск, фильтры и просмотр упражнений.
Подробности упражнения = модальное окно.
Полная карточка упражнения = отдельный экран.
Запуск упражнения = через быстрый старт / настройку упражнения.
```

На основном экране каталога не должно быть боковой панели с деталями упражнения.

---

# Общая структура экрана

Экран состоит из следующих зон:

1. Верхняя системная панель.
2. Левое меню.
3. Заголовок экрана.
4. Поиск упражнения.
5. Переключатель вида.
6. Сортировка.
7. Фильтры.
8. Категории мышц и оборудования.
9. Счётчик найденных упражнений.
10. Скроллируемая область карточек упражнений.
11. Кнопка быстрого возврата наверх.
12. Модальное окно подробностей упражнения.

---

# Верхняя системная панель

Верхняя панель такая же, как на остальных экранах Forma.

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод]
[Правый привод]
[Безопасность включена]
[СТОП]
```

## Элементы верхней панели

| Элемент            | Назначение                     |
| ------------------ | ------------------------------ |
| **Forma**          | Логотип и название приложения. |
| **Алексей**        | Текущий пользователь.          |
| **Тренажёр готов** | Общий статус тренажёра.        |
| **Левый привод**   | Статус левого привода.         |
| **Правый привод**  | Статус правого привода.        |
| **Безопасность включена** | Статус системы безопасности. |
| **СТОП**           | Аварийная остановка.           |

# Кнопка быстрого возврата наверх

Внутри области карточек должна быть кнопка быстрого возврата наверх.

```text
↑
```

или:

```text
↑ Наверх
```

## Когда показывать

Кнопка появляется, когда пользователь прокрутил список вниз.

Например:

```text
после прокрутки ниже 1–2 экранов
```

## Расположение

Лучшее место:

```text
справа снизу внутри скроллируемой области карточек
```

## Поведение

При нажатии:

```text
область карточек плавно прокручивается к началу списка
```

После возврата наверх кнопка скрывается.

# Модальное окно упражнения

Подробности упражнения показываются **не в боковой панели**, а в модальном окне.

## Главное правило

```text
Клик по карточке / кнопке “Открыть”
→ открыть модальное окно упражнения
```

После закрытия модального окна пользователь должен вернуться в ту же позицию скролла.

---

# Размер модального окна

Для 4K-монитора модальное окно должно быть крупным.

Рекомендуемый размер:

```text
ширина: 65–75% экрана
высота: 75–85% экрана
```

Фон каталога за модальным окном:

* затемняется;
* слегка размывается;
* остаётся видимым, чтобы пользователь не терял контекст.

# Совместимость упражнения

В модальном окне должен быть блок совместимости.

## Что учитывается

* усталость мышц;
* уровень пользователя;
* чёрный список;
* доступное оборудование;
* последние тренировки;
* цели пользователя.

## Возможные состояния

| Статус                   | Значение                     |
| ------------------------ | ---------------------------- |
| Отлично подходит         | Можно выполнять сегодня.     |
| Подходит                 | Можно выполнять.             |
| Осторожно                | Лучше снизить нагрузку.      |
| Не рекомендуется сегодня | Целевые мышцы устали.        |
| В чёрном списке          | Не предлагать автоматически. |
| Недоступно               | Нет оборудования.            |

## Пример

```text
Совместимость сегодня:
Осторожно

Грудь имеет умеренную усталость.
Рекомендуется снизить объём или вес.
```

# Поведение кнопок

## Начать

```text
Каталог
→ модальное окно упражнения

→ Калибровка
```

## Добавить в тренировку

Если каталог открыт из конструктора:

```text
добавить упражнение в текущую программу
```

Если каталог открыт отдельно:

```text
Куда добавить упражнение?

[В новую тренировку]
[В существующую программу]
[В сегодняшнюю тренировку]
```

---

## Открыть подробно

Переход на отдельный экран:

```text
Карточка упражнения
```

На отдельной карточке можно показать:

* полное описание;
* все видео;
* историю выполнения;
* рабочие веса;
* прогресс по упражнению;
* похожие упражнения;
* сохранённые калибровки.

---

## В избранное

Добавляет упражнение в избранное пользователя.

```text
Упражнение добавлено в избранное.
```

---

```text
Упражнение больше не будет предлагаться
```

Важно:

```text
Упражнение остаётся доступным в каталоге.
```

# ID упражнения

Если в JSON нет `id`, его можно брать из имени папки.

Пример:

```text
barbell-floor-press
```

Этот ID используется для:

* избранного;
* чёрного списка;
* истории;
* программ;
* калибровок;
* прогресса.

# Пути к видео

Если упражнение лежит в папке:

```text
/exercises/barbell-floor-press/
```

а в JSON указано:

```json
"male_videos": [
  "male-Barbell-barbell-floor-press-side.mp4"
]
```

полный путь формируется так:

```text
/exercises/barbell-floor-press/male-Barbell-barbell-floor-press-side.mp4
```

# Цветовая логика

| Цвет      | Использование                                         |
| --------- | ----------------------------------------------------- |
| Золотой   | Активные фильтры, основные кнопки, выбранные элементы |
| Зелёный   | Рекомендуется, готово, совместимо                     |
| Жёлтый    | Осторожно, лёгкое предупреждение                      |
| Оранжевый | Среднее предупреждение                                |
| Красный   | СТОП, чёрный список, критические ошибки               |
| Серый     | Второстепенные данные                                 |

# Ключевые требования

1. Экран рассчитан на большой 4K-монитор.
2. Данные упражнений читаются из папки `/exercises`.
3. У каждого упражнения своя папка с JSON и видео.
4. Видео имеют горизонтальный формат `1280×720`.
5. Все видео отображаются в интерфейсе как `16:9`.
6. Основное название упражнения — `name_ru`.
7. Английское название — `name`.
8. Поиск работает на русском и английском.
9. Список упражнений не использует пагинацию.
10. Скроллятся только карточки упражнений.
11. Верхняя панель, левое меню, поиск и фильтры остаются на месте.
12. Должна быть кнопка быстрого возврата наверх.
13. Подробности упражнения открываются в модальном окне.
14. После закрытия модального окна сохраняется позиция скролла.
15. В модальном окне показывается видео, техника и параметры упражнения.
16. В модальном окне должны быть переключатели модели и ракурса.
17. Кнопка `Начать` ведёт в быстрый старт с выбранным упражнением.
18. Кнопка `Добавить в тренировку` добавляет упражнение в программу или предлагает выбрать место добавления.
19. Кнопка `Открыть подробно` ведёт на отдельный экран карточки упражнения.
20. Упражнения из чёрного списка не скрываются, но помечаются.
21. Избранные упражнения должны иметь отдельную метку.
22. Каталог учитывает усталость мышц и показывает совместимость.
23. Каталог должен работать без интернета.
24. Интерфейс должен быть крупным, тёмным, красивым и удобным для сенсорного управления.
