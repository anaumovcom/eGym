# Экран 2 — Профиль пользователя

## Назначение экрана

Экран **“Профиль пользователя”** в приложении **Forma** нужен для хранения и редактирования персональных данных пользователя, которые влияют на подбор тренировок, рекомендации, цели, фотофиксацию и исключение нежелательных упражнений.

Этот экран **не отвечает за настройки тренажёра** и **не отвечает за безопасность механики**.

---

## Главное правило разделения

```text
Профиль пользователя = личные данные, цели, тело, фото, предпочтения.
Настройки тренажёра = безопасность, приводы, ШВП, лимиты, диагностика.
Упражнение = техника, амплитуда, калибровка, нижняя и верхняя точки.
Прогресс = история тренировок, рекорды, графики, аналитика.
```

---

## Что не должно быть на этом экране

Из профиля пользователя убираем:

* настройки безопасности тренажёра;
* PIN-код тренажёра;
* параметры ШВП;
* параметры сервоприводов;
* максимальную скорость грифа;
* минимальную безопасную высоту;
* общие лимиты тренажёра;
* историю тренировок;
* подробную аналитику прогресса;
* сервисные функции;
* диагностику оборудования.

Минимальная и максимальная безопасная высота должны зависеть от конкретного упражнения и его калибровки, а не от профиля пользователя.

---

# Общая структура экрана

Экран состоит из следующих зон:

1. Верхняя системная панель.
2. Кнопка назад.
3. Заголовок экрана.
4. Верхняя карточка пользователя.
5. Вкладки профиля.
6. Контент активной вкладки.
7. Нижняя панель действий.

---

# Верхняя системная панель

Верхняя панель должна быть такой же, как на других экранах Forma.

## Состав панели

```text
Forma

[ Тренажёр готов ] [ Левый привод: подключён ] [ Правый привод: подключён ] [ Безопасность включена ] [ СТОП ]
```

## Элементы

| Элемент                      | Назначение                         |
| ---------------------------- | ---------------------------------- |
| **Forma**                    | Логотип и название приложения.     |
| **Тренажёр готов**           | Общий статус системы.              |
| **Левый привод: подключён**  | Статус левого привода.             |
| **Правый привод: подключён** | Статус правого привода.            |
| **Безопасность включена**    | Статус системы безопасности.       |
| **СТОП**                     | Аварийная остановка, всегда видна. |

---

# Заголовок экрана

Основной заголовок:

```text
Профиль пользователя
```

Слева под верхней панелью:

```text
← Назад
```

Кнопка `Назад` возвращает пользователя на предыдущий экран.

---

# Верхняя карточка пользователя

Верхняя карточка пользователя всегда отображается над вкладками.

## Назначение

Она даёт быстрый контекст: чей профиль открыт и какие основные параметры у пользователя.

## Содержимое карточки

```text
[Фото]

Алексей

Цель:
сила + общая форма

Рост:
183 см

Вес:
92.4 кг

Уровень:
средний

[Редактировать профиль]
[Сделать фото прогресса]
```

## Визуальные требования

* карточка широкая;
* расположена по центру;
* фон тёмный, полупрозрачный;
* мягкая золотая подсветка важных элементов;
* фото пользователя крупное и хорошо читаемое;
* данные не должны выглядеть как скучная анкета;
* кнопки справа должны быть крупными и удобными для сенсорного экрана.

---

# Основные действия в верхней карточке

## Редактировать профиль

Кнопка:

```text
Редактировать профиль
```

Назначение:

* включает режим редактирования;
* позволяет менять имя, рост, вес, цель, уровень и другие параметры;
* после изменений пользователь должен нажать `Сохранить изменения`.

---

## Сделать фото прогресса

Кнопка:

```text
Сделать фото прогресса
```

Назначение:

* открывает отдельный экран фотофиксации;
* тренажёр помогает сделать фото в правильной позе;
* фото сохраняется в профиль пользователя.

Важно: сам процесс фотографирования должен быть отдельным экраном, а не модальным окном внутри профиля.

---

# Вкладки профиля

Финальный набор вкладок:

| № | Вкладка                      | Назначение                                             |
| - | ---------------------------- | ------------------------------------------------------ |
| 1 | **Сводка**                   | Быстрый обзор профиля и ключевых данных.               |
| 2 | **Общее**                    | Основные данные и персонализация профиля.              |
| 3 | **Цели**                     | Цели тренировок и параметры автоподбора программ.      |
| 4 | **Данные тела**              | Вес, замеры, данные с весов, история измерений.        |
| 5 | **Фото прогресса**           | Последние фото, история фото, сравнение, новое фото.   |
| 6 | **Чёрный список упражнений** | Упражнения, которые не нужно предлагать автоматически. |

# Вкладка 1 — Сводка

## Назначение

Вкладка **“Сводка”** показывает краткий обзор профиля без необходимости заходить в каждую вкладку отдельно.

Это стартовая вкладка экрана профиля.

---

## Основные блоки

### 1. Основная информация

```text
Основная информация

Имя: Алексей
Рост: 183 см
Вес: 92.4 кг
Уровень: средний
Основная цель: сила + общая форма
```

---

### 2. Краткая сводка

```text
Краткая сводка

Дата последнего фото: 12 мая 2024
Текущий вес: 92.4 кг
Цель: сила + общая форма
Частота тренировок: 4–5 раз в неделю
Рекомендация: Сегодня лучше спина
```

---

### 3. Последние данные тела

```text
Последние данные тела

Вес: 92.4 кг
Изменение: -0.6 кг

Талия: 92 см
Изменение: -1 см
```

---

### 4. Фото прогресса

Блок показывает мини-превью последних фото:

```text
Фото прогресса

[Спереди] [Сбоку] [Сзади]

[Открыть]
```

---

### 5. Чёрный список

Краткий блок:

```text
Чёрный список

Исключено упражнений: 3

Тяга за голову
Скручивания
Жим штанги за голову
```

---

## Поведение вкладки

Сводка должна быть обзорной.
Она не должна превращаться в полноценный экран аналитики.

Из неё можно быстро перейти:

* к данным тела;
* к фото прогресса;
* к чёрному списку;
* к редактированию профиля.

---

# Вкладка 2 — Общее

## Назначение

Вкладка **“Общее”** содержит основные данные пользователя и настройки персонализации профиля.

---

## Блок 1 — Основные данные

```text
Основные данные

Имя: Алексей
Рост: 183 см
Вес: 92.4 кг
Уровень подготовки: средний
Основная цель: сила + общая форма
Дата создания профиля: 03 мая 2024
```

Каждое поле можно редактировать через маленькую кнопку с иконкой карандаша.

---

## Блок 2 — Профиль и персонализация

```text
Профиль и персонализация

Аватар: [Изменить]
Язык интерфейса: Русский
Единицы измерения: кг / см
Тема интерфейса: Тёмная
Напоминать о фото прогресса перед тренировкой: да
```

---

## Блок 3 — Контакт и заметки

```text
Контакт и заметки

Email: не указан
Личные заметки: Добавьте заметки о пользователе...
```

Email не является обязательным.

---

## Блок 4 — Краткое описание

```text
Краткое описание

Краткое описание пользователя:
тренировки, особенности, предпочтения и другая важная информация...
```

---

## Что здесь не должно быть

На вкладке `Общее` не должно быть:

* параметров тренажёра;
* настроек приводов;
* PIN-кодов;
* истории тренировок;
* сложной аналитики;
* калибровок упражнений.

---

# Вкладка 3 — Цели

## Назначение

Вкладка **“Цели”** определяет, как Forma будет подбирать и генерировать тренировки для пользователя.

---

## Блок 1 — Главная цель

Основная выбранная цель:

```text
Главная цель

Сила + общая форма
```

Дополнительные варианты:

```text
Мышечная масса
Поддержание активности
Выносливость
Восстановительный режим
```

Пользователь может выбрать одну главную цель.

---

## Блок 2 — Параметры тренировок

```text
Параметры тренировок

Частота: 3 раза в неделю
Длительность: 45 минут
Стиль: классическая силовая тренировка
Автогенерация программ: включена
```

---

## Блок 3 — Приоритетные мышечные группы

```text
Приоритетные мышечные группы

[Грудь] [Спина] [Ноги] [Плечи] [Руки] [Кор]
```

Выбранные группы подсвечиваются золотым цветом.

Пример выбранных:

```text
Грудь
Спина
Ноги
```

---

## Блок 4 — Что учитывать при подборе

```text
Что учитывать при подборе

- Избегать слишком длинных тренировок
- Баланс силовых и лёгких дней
```

---

## Как используются цели

Цели влияют на:

* автоматическую генерацию тренировок;
* рекомендации на главной странице;
* подбор упражнений;
* баланс мышечных групп;
* длительность тренировки;
* количество подходов и повторений;
* частоту тренировок;
* приоритеты восстановления.

---

# Вкладка 4 — Данные тела

## Назначение

Вкладка **“Данные тела”** хранит измеримые параметры пользователя.

Это не экран оценки внешности, а нейтральный инструмент наблюдения за изменениями, весом и замерами.

---

## Блок 1 — Текущие показатели

```text
Текущие показатели

Вес: 92.4 кг
Талия: 97 см
Грудь: 108 см
Бёдра: 101 см
Бицепс: 38 см
Бедро: 58 см

Последнее измерение: сегодня, 12 мая 2024
```

---

## Блок 2 — Динамика

Показывает график изменения веса и/или замеров.

```text
Динамика

За месяц: -1.2 кг
Последнее измерение: сегодня
```

На графике:

* линия изменения веса;
* точки измерений;
* даты;
* краткий итог.

---

## Блок 3 — Источник данных

```text
Источник данных

Умные весы: не подключены

[Подключить устройство]
[Ввести вручную]
```

Если весы подключены, блок может выглядеть так:

```text
Источник данных

Умные весы: подключены
Последняя синхронизация: сегодня, 08:40
```

---

## Блок 4 — История измерений

```text
История измерений

12 мая 2024 — 92.4 кг — 97 см — 108 см — 101 см
5 мая 2024 — 93.1 кг — 98 см — 108 см — 101 см
28 апреля 2024 — 94.2 кг — 99 см — 109 см — 102 см

[Показать всю историю]
```

---

## Блок 5 — Краткий вывод

```text
Краткий вывод

Вес снижается плавно,
динамика стабильная.
```

---

## Какие данные можно хранить

```text
Вес
Талия
Грудь
Бёдра
Бицепс
Бедро
Плечи
Дата измерения
Источник данных
Комментарий
```

# Вкладка 5 — Фото прогресса

## Назначение

Вкладка **“Фото прогресса”** хранит фотофиксации пользователя и помогает сравнивать изменения во времени.

Важно: интерфейс должен быть нейтральным и поддерживающим.
Он не должен оценивать внешность пользователя.

---

## Блок 1 — Последняя фотофиксация

```text
Последняя фотофиксация

Дата: 12 мая 2024

[Спереди]
[Сбоку]
[Сзади]

Следующее фото рекомендуется через 7 дней
```

---

## Блок 2 — Действия

```text
Действия

[Сделать новое фото]
Зафиксировать текущую форму

[Сравнить фото]
Визуальное сравнение прогресса

[Открыть галерею]
Просмотреть все фото
```

---

## Блок 3 — История фото

```text
История фото

01 мая 2024
12 мая 2024
20 апреля 2024
```

История должна выглядеть как горизонтальная временная шкала.

У каждой даты:

* фото спереди;
* фото сбоку;
* фото сзади.

---

## Блок 4 — Подсказки

```text
Подсказки

- Одинаковое освещение
- Ровная стойка
- Камера на уровне груди
```

---

## Отдельный экран фотофиксации

При нажатии `Сделать новое фото` открывается отдельный экран:

```text
Фотофиксация прогресса
```

На отдельном экране должны быть:

* подсказка по расстоянию до камеры;
* силуэт для выравнивания позы;
* таймер;
* фото спереди;
* фото сбоку;
* фото сзади;
* возможность переснять;
* возможность пропустить;
* сохранение в профиль.

---

# Вкладка 6 — Чёрный список упражнений

## Назначение

Вкладка **“Чёрный список упражнений”** нужна для упражнений, которые пользователь не хочет видеть в автоматически сгенерированных программах.

Это не запрет на выполнение упражнения вообще.
Это исключение из рекомендаций и автогенерации.

---

## Блок 1 — Добавить упражнение

```text
Добавить упражнение в чёрный список

[Найти упражнение...] [Добавить]
```

Поиск должен работать по каталогу упражнений.

---

## Блок 2 — Исключённые упражнения

```text
Исключённые упражнения

Жим штанги за голову
Причина: Не предлагать
[Удалить из списка]

Тяга к подбородку
Причина: Не предлагать
[Удалить из списка]

Глубокий присед
Причина: Некомфортно
[Удалить из списка]

Выпады
Причина: Некомфортно
[Удалить из списка]

Скручивания
Причина: Не предлагать
[Удалить из списка]
```

---

## Блок 3 — Как это работает

```text
Как это работает

Упражнения в этом списке не будут предлагаться
в автоматически сгенерированных тренировках.

Они останутся доступными в каталоге,
и вы сможете добавить их вручную при необходимости.

Вы полностью контролируете список
и можете изменять его в любой момент.
```

---

## Блок 4 — Быстрые действия

```text
Быстрые действия

[Очистить список]
[Импортировать из рекомендаций]
```

Кнопка `Очистить список` должна быть визуально опасной, но не слишком яркой.
Перед очисткой нужно показать подтверждение.

---

## Поведение упражнений из чёрного списка

Если упражнение добавлено в чёрный список:

* оно не попадает в автоматически созданные программы;
* оно не показывается в рекомендациях;
* оно остаётся доступным в каталоге упражнений;
* его можно добавить вручную;
* при ручном добавлении можно показать предупреждение.

Пример предупреждения:

```text
Это упражнение находится в чёрном списке пользователя.

Оно не предлагается автоматически,
но вы можете добавить его вручную.
```

---

# Нижняя панель действий

Внизу экрана всегда отображаются действия:

```text
[Сохранить изменения] [Отменить]
```

## Сохранить изменения

Основная кнопка.

Визуальный стиль:

* золотая;
* крупная;
* хорошо заметная;
* с иконкой галочки.

---

## Отменить

Вторичная кнопка.

Визуальный стиль:

* тёмная;
* менее заметная;
* с иконкой крестика.

---

# Состояния экрана

## 1. Просмотр

Пользователь просто смотрит профиль.

```text
[Редактировать профиль]
```

---

## 2. Редактирование

Поля становятся редактируемыми.

```text
[Сохранить изменения] [Отменить]
```

---

## 3. Есть несохранённые изменения

Если пользователь пытается выйти:

```text
Есть несохранённые изменения

[Сохранить]
[Выйти без сохранения]
[Остаться]
```

---

## 4. Весы не подключены

```text
Умные весы не подключены

Можно подключить устройство
или ввести данные вручную.
```

---

## 5. Нет фото прогресса

```text
Фото прогресса пока нет

Сделайте первую фотофиксацию,
чтобы отслеживать изменения.
```

---

## 6. Чёрный список пуст

```text
Чёрный список пуст

Упражнения из каталога будут использоваться
при генерации программ без ограничений.
```

---

# Визуальный стиль

Экран должен продолжать стиль приложения Forma.

## Основные признаки

* тёмный фон;
* фон с едва заметным тренажёром или залом;
* золотые акценты;
* зелёные статусы;
* красная кнопка `СТОП`;
* большие скруглённые карточки;
* мягкие тени;
* крупные элементы для сенсорного экрана;
* 4K-композиция с большим количеством воздуха;
* единая сетка между всеми вкладками.

---

# Цветовая логика

| Цвет    | Использование                                 |
| ------- | --------------------------------------------- |
| Золотой | Активная вкладка, важные кнопки, акценты.     |
| Зелёный | Подключено, включено, положительная динамика. |
| Красный | `СТОП`, опасные действия, ошибки.             |
| Серый   | Второстепенный текст, неактивные элементы.    |
| Тёмный  | Фон, карточки, панели.                        |

---

# Приоритеты интерфейса

## Главное

1. Профиль пользователя.
2. Основные данные.
3. Цели.
4. Фото прогресса.
5. Чёрный список упражнений.
6. Сохранение изменений.

## Второстепенное

1. Персонализация интерфейса.
2. Заметки.
3. История измерений.
4. Подсказки.
5. Быстрые действия.

# Навигация

## Переходы с экрана

| Действие                 | Куда ведёт                             |
| ------------------------ | -------------------------------------- |
| `Назад`                  | Предыдущий экран.                      |
| `Редактировать профиль`  | Режим редактирования текущей вкладки.  |
| `Сделать фото прогресса` | Экран фотофиксации прогресса.          |
| `Открыть фото прогресса` | Вкладка фото прогресса или галерея.    |
| `Добавить упражнение`    | Поиск по каталогу упражнений.          |
| `Удалить из списка`      | Удаление упражнения из чёрного списка. |
| `Подключить устройство`  | Настройки подключения умных весов.     |
| `Сохранить изменения`    | Сохранение данных профиля.             |
| `Отменить`               | Отмена изменений.                      |
| `СТОП`                   | Аварийная остановка тренажёра.         |


# Ключевые требования

1. Экран рассчитан на большой 4K-монитор.
2. Все вкладки должны быть в едином стиле.
3. Верхняя карточка пользователя остаётся одинаковой на всех вкладках.
4. Вкладки меняют только центральный контент.
5. В профиле нет настроек безопасности тренажёра.
6. В профиле нет параметров ШВП и сервоприводов.
7. Фото прогресса есть в профиле, но процесс съёмки вынесен в отдельный экран.
8. Чёрный список упражнений влияет только на автогенерацию программ.
9. История тренировок и активность будут отдельным экраном.
10. Интерфейс должен быть красивым, премиальным и удобным для сенсорного управления.
