Вкладка **“Приводы и ШВП”** — одна из самых важных в настройках тренажёра. Это должен быть не маленький блок “левый привод подключён / правый подключён”, а полноценный экран управления механикой.

# Вкладка 3 — Приводы и ШВП

## Назначение вкладки

Вкладка нужна для настройки и контроля механической части тренажёра:

```text
левый привод;
правый привод;
синхронизация сторон;
ШВП;
позиции;
скорости;
ускорения;
ограничения;
ручное перемещение;
профили движения;
ошибки;
обслуживание;
параметры Modbus / CAN / связи;
```

Главная задача:

```text
Убедиться, что приводы работают синхронно, безопасно и предсказуемо.
```

---

# Главная структура вкладки

Я бы разделил её на 8 больших блоков:

| № | Блок                           | Назначение                                             |
| - | ------------------------------ | ------------------------------------------------------ |
| 1 | **Общий статус механики**      | Быстро понять, всё ли нормально.                       |
| 2 | **Левый и правый привод**      | Подключение, ошибки, позиция, температура, ток.        |
| 3 | **Синхронизация сторон**       | Рассинхрон, выравнивание, допуски.                     |
| 4 | **Параметры движения**         | Скорость, ускорение, плавность, режимы перемещения.    |
| 5 | **Параметры ШВП**              | Шаг, ход, направление, лимиты, коэффициенты пересчёта. |
| 6 | **Ручное управление**          | Безопасное перемещение грифа для обслуживания.         |
| 7 | **Профили движения**           | Обычный режим, калибровка, проверка диапазона, сервис. |
| 8 | **Обслуживание и диагностика** | Смазка, люфт, шум, ресурс, тесты.                      |

# 1. Общий статус механики

## Что показывать

```text
Статус механики:
готова к работе

Левый привод:
подключён

Правый привод:
подключён

Синхронизация:
норма

Разница сторон:
0.4 мм

Последняя диагностика:
сегодня, 08:40

Запуск упражнений:
разрешён
```

## Возможные состояния

| Состояние                 | Что значит                                  |
| ------------------------- | ------------------------------------------- |
| **Готова к работе**       | Всё нормально.                              |
| **Есть предупреждения**   | Можно работать, но есть замечания.          |
| **Требуется диагностика** | Нужно проверить систему.                    |
| **Запуск заблокирован**   | Есть критическая ошибка.                    |
| **Сервисный режим**       | Управление доступно только вручную и с PIN. |

# 3. Синхронизация сторон

Это один из ключевых блоков для тренажёра с двумя ШВП.

## Основные данные

```text
Синхронизация сторон

Левая сторона:
862.4 мм

Правая сторона:
862.0 мм

Разница:
0.4 мм

Допустимый рассинхрон:
5 мм

Статус:
норма
```

---

## Цветовая логика

| Разница | Статус                        |
| ------- | ----------------------------- |
| 0–2 мм  | Норма                         |
| 2–5 мм  | Допустимо                     |
| 5–8 мм  | Предупреждение                |
| >8 мм   | Критично, запуск заблокирован |

Значения должны быть настраиваемыми, но с безопасными ограничениями.

---

## Действия

```text
[Проверить синхронность]
[Выровнять стороны]
[Открыть диагностику]
```

## Важно

Кнопка **“Выровнять стороны”** должна быть защищена:

* только после подтверждения зоны движения;
* только в сервисном режиме;
* желательно по PIN;
* с низкой скоростью;
* с низким моментом;
* с возможностью мгновенной остановки.

# 4. Параметры движения

Этот блок нужен для настройки того, как гриф двигается.

## Основные параметры

```text
Максимальная скорость:
80 мм/с

Скорость калибровки:
20 мм/с

Скорость показа диапазона:
15 мм/с

Скорость сервисного перемещения:
10 мм/с

Ускорение:
120 мм/с²

Плавность старта:
включена

Плавность остановки:
включена
```

---

# Настройки движения

## Скорость

Разделить по сценариям:

| Параметр                      | Назначение                                   |
| ----------------------------- | -------------------------------------------- |
| **Скорость упражнения**       | Основное движение в режиме нагрузки.         |
| **Скорость калибровки**       | Ручная калибровка нижней/верхней точки.      |
| **Скорость показа диапазона** | Когда тренажёр показывает крайние положения. |
| **Сервисная скорость**        | Ручное обслуживание.                         |
| **Скорость возврата**         | Возврат грифа в стартовое положение.         |

---

## Ускорение

```text
Ускорение:
низкое / среднее / высокое
```

Лучше показывать пользователю простые уровни, а внутри хранить числовые значения.

```text
Низкое — максимально плавно
Среднее — стандартно
Высокое — быстрее, только для опытных
```

---

## Jerk / плавность

Если в системе будет управление рывком:

```text
Плавность изменения скорости:
мягкая
стандартная
резкая
```

В пользовательском интерфейсе лучше не писать `jerk`, а назвать:

```text
Плавность движения
```

# 5. Параметры ШВП

Этот блок больше инженерный, но его нужно предусмотреть.

## Что хранить

```text
Тип ШВП:
SFE3232

Шаг ШВП:
32 мм/оборот

Длина хода:
2000 мм

Рабочий ход:
0–1850 мм

Направление левого ШВП:
обычное

Направление правого ШВП:
инвертированное

Передаточное отношение:
1:1

Единицы позиции:
мм

Нулевая точка:
нижняя / верхняя / пользовательская
```

---

# Основные параметры ШВП

| Параметр                   | Зачем нужен                        |
| -------------------------- | ---------------------------------- |
| **Модель ШВП**             | Для справки и обслуживания.        |
| **Шаг винта**              | Пересчёт оборотов в миллиметры.    |
| **Длина хода**             | Ограничение движения.              |
| **Рабочий ход**            | Реально разрешённый диапазон.      |
| **Направление вращения**   | Чтобы стороны двигались одинаково. |
| **Передаточное отношение** | Если есть ремень/редуктор.         |
| **Нулевая точка**          | Откуда считается координата.       |
| **Коэффициент пересчёта**  | Для точного позиционирования.      |

# 6. Лимиты движения

Очень важный блок.

## Глобальные лимиты

```text
Минимальная системная позиция:
0 мм

Максимальная системная позиция:
1850 мм

Мягкий нижний лимит:
50 мм

Мягкий верхний лимит:
1800 мм

Запас безопасности сверху:
50 мм

Запас безопасности снизу:
50 мм
```

---

# Важно

Эти лимиты не равны калибровке упражнения.

```text
Глобальные лимиты = физические пределы тренажёра.
Калибровка упражнения = рабочий диапазон конкретного упражнения.
```

---

# Логика лимитов

| Тип лимита                      | Значение                                          |
| ------------------------------- | ------------------------------------------------- |
| **Физический предел**           | Абсолютно запрещённая зона.                       |
| **Мягкий лимит**                | Система не должна туда заходить в обычном режиме. |
| **Рабочий диапазон упражнения** | Задаётся на экране настройки упражнения.          |
| **Сервисный диапазон**          | Доступен только в сервисном режиме.               |

# 8. Профили движения

Очень полезный блок.

Профили позволяют иметь разные параметры движения для разных сценариев.

## Профили

| Профиль             | Назначение                        |
| ------------------- | --------------------------------- |
| **Тренировка**      | Основная работа с нагрузкой.      |
| **Калибровка**      | Мягкое ручное перемещение.        |
| **Показ диапазона** | Низкий момент, низкая скорость.   |
| **Сервис**          | Очень медленное перемещение.      |
| **Аварийный стоп**  | Остановка и блокировка.           |
| **Гостевой режим**  | Ограниченная скорость и нагрузка. |

---

## Пример

```text
Профили движения

Тренировка:
скорость средняя
момент по режиму нагрузки

Калибровка:
скорость низкая
момент низкий

Показ диапазона:
скорость очень низкая
момент низкий

Сервис:
скорость очень низкая
только удержание кнопки
```

---

# 9. Ограничение момента

Так как ты планируешь, чтобы тренажёр показывал диапазон с низким моментом, это нужно выделить.

## Настройки

```text
Момент в режиме показа диапазона:
низкий

Момент в режиме калибровки:
низкий

Момент в сервисном режиме:
очень низкий

Момент в тренировке:
по выбранной нагрузке
```

В интерфейсе лучше не показывать сложные Н·м обычному пользователю, а использовать уровни:

```text
Очень низкий
Низкий
Средний
Высокий
```

А в инженерном режиме можно показывать числовые значения.

# 10. Ручное управление грифом

Нужен блок, но только в сервисном/защищённом режиме.

## Безопасный UI

```text
Ручное управление

[Удерживать вверх]
[Удерживать вниз]
[Стоп]

Точный шаг:
[-5 мм] [+5 мм]
[-1 мм] [+1 мм]

Текущая позиция:
862 мм
```

---

# Важные правила ручного управления

```text
Движение только при удержании кнопки.
При отпускании кнопки движение останавливается.
Перед движением нужно подтвердить свободную зону.
СТОП всегда активен.
Если рассинхрон критический — управление блокируется.
Если привод не подключён — управление блокируется.
```

# 11. Нулевая позиция и homing

Если у тренажёра будет процедура поиска нуля, её нужно вынести в защищённый раздел.

## Блок

```text
Нулевая позиция

Статус:
задана

Последнее обновление:
12 мая, 08:20

[Проверить нулевую позицию]
[Переустановить ноль]
```

## Важно

Кнопка **“Переустановить ноль”** опасная. Она должна быть:

* только в сервисном режиме;
* по PIN;
* с подтверждением;
* с понятным предупреждением.

# Ключевые требования для вкладки

1. Вкладка должна быть полноценным центром управления механикой.
2. Нужно отдельно показывать левый и правый привод.
3. Нужно показывать позиции обеих сторон.
4. Нужно показывать рассинхрон.
5. Критический рассинхрон должен блокировать запуск.
6. Нужно иметь настройки профилей движения.
7. Профиль “Показ диапазона” должен использовать низкую скорость и низкий момент.
8. Профиль “Калибровка” должен быть мягким и безопасным.
9. Ручное управление только в защищённом режиме.
10. Движение в ручном режиме — только при удержании кнопки.
11. Должны быть глобальные лимиты движения.
12. Глобальные лимиты не равны калибровке упражнения.
13. Параметры ШВП должны быть доступны в инженерном режиме.
14. Настройки связи должны быть доступны в инженерном режиме.
15. Переустановка нуля только по PIN и с подтверждением.
16. Ошибки приводов должны быть понятны обычному пользователю.
17. Технические коды можно показывать в раскрытом виде.
18. Должен быть блок обслуживания ШВП.
19. Кнопка `СТОП` всегда видна.
20. Интерфейс должен быть крупным и понятным для 4K-монитора.
