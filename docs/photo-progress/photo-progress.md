# Промежуточный экран — Фотофиксация прогресса

## Назначение экрана

Экран **“Фотофиксация прогресса”** нужен для нейтральной фиксации фото пользователя по датам и ракурсам.

Он не оценивает внешность пользователя и не сравнивает его с другими людьми.

Главная задача:

```text
Помочь сделать одинаковые фото прогресса:
спереди, сбоку и сзади,
с понятной позой, расстоянием до камеры и стабильным освещением.
```

---

# Где используется экран

Фотофиксация может открываться из разных сценариев:

```text
Главная → Начать тренировку
Сегодняшняя тренировка → Начать тренировку
Быстрый старт → Начать
Библиотека программ → Начать сегодня
Профиль пользователя → Сделать фото прогресса
Прогресс → Фото прогресса → Сделать новое фото
Итог тренировки → Сделать фото после тренировки
```

`Проверка необходимости фото прогресса` перед этим экраном — фоновая логика, а не отдельный экран. Если фото не требуется, пользователь сразу попадает на экран `Настройка упражнения`.

---

# Главное правило

Фото прогресса не должно быть обычным блоком на главной, календаре, быстром старте или библиотеке программ.

Оно появляется отдельным шагом только когда:

* пришло время плановой фотофиксации;
* пользователь нажал `Сделать фото прогресса` вручную;
* после тренировки Forma предлагает зафиксировать результат;
* пользователь открыл вкладку фото прогресса и выбрал новое фото.

---

# Место в сценарии старта тренировки

Если фото требуется перед тренировкой:

```text
Нажать “Начать”
→ Проверка необходимости фото прогресса
→ Фотофиксация прогресса
→ Настройка упражнения
→ Выполнение упражнения
```

Если фото не требуется:

```text
Нажать “Начать”
→ Настройка упражнения
→ Выполнение упражнения
```

---

# Когда показывать автоматически

Forma может предложить фотофиксацию перед тренировкой, если:

* прошло заданное количество дней с последнего фото;
* пользователь включил напоминания перед тренировкой;
* сегодня запланирована контрольная дата;
* пользователь давно не делал фото в одном из обязательных ракурсов;
* стартует новая тренировочная программа;
* завершился этап программы на несколько недель.

Автоматическое появление не должно быть навязчивым.

Пользователь всегда может выбрать:

```text
[Сделать сейчас]
[Напомнить после тренировки]
[Пропустить сегодня]
```

---

# Верхняя системная панель

Панель такая же, как на остальных экранах Forma:

```text
Forma  [Алексей]  [Тренажёр готов]  [Левый привод: подключён]  [Правый привод: подключён]  [Безопасность включена]  [СТОП]
```

Кнопка `СТОП` остаётся видимой, даже если тренажёр не движется.

---

# Заголовок экрана

```text
Фотофиксация прогресса
```

Подзаголовок:

```text
Сделайте фото в одинаковых ракурсах, чтобы отслеживать изменения по датам.
```

---

# Что важно объяснить пользователю

```text
Фото нужны только для личного прогресса.
Forma не оценивает внешность и не сравнивает вас с другими.
Старайтесь сохранять одинаковую позу, расстояние и освещение.
```

---

# Общая структура экрана

Экран состоит из зон:

1. Верхняя системная панель.
2. Заголовок и объяснение.
3. Блок подготовки к фото.
4. Вид с камеры или заглушка камеры.
5. Силуэт / контур позы.
6. Выбор ракурса.
7. Таймер съёмки.
8. Предпросмотр снимков.
9. Действия сохранения или пропуска.
10. Подсказки приватности.

---

# Ракурсы

Минимальный набор:

```text
Спереди
Сбоку
Сзади
```

Дополнительно позже можно добавить:

```text
левая сторона;
правая сторона;
произвольный ракурс;
контрольная поза.
```

---

# Состояние ракурсов

```text
Спереди — не снято
Сбоку — не снято
Сзади — не снято
```

После съёмки:

```text
Спереди — готово
Сбоку — готово
Сзади — готово
```

---

# Подготовка к фото

Блок подготовки:

```text
Подготовка

1. Встаньте на отмеченное место.
2. Совместите силуэт на экране с контуром тела.
3. Держите нейтральную позу.
4. Сохраняйте одинаковое освещение.
5. Нажмите “Сделать фото” или включите таймер.
```

---

# Вид с камеры

Если камера доступна:

```text
[Живой вид с камеры]
[Силуэт позы]
[Подсказка расстояния]
```

Если камера недоступна:

```text
Камера недоступна

Проверьте подключение камеры или пропустите фотофиксацию.

[Повторить проверку]
[Пропустить]
```

---

# Силуэт и выравнивание

Силуэт должен помогать занять одинаковое положение, но не должен оценивать тело.

Возможные подсказки:

```text
Отойдите немного назад
Станьте чуть левее
Повернитесь боком
Сохраняйте нейтральную позу
```

Не использовать формулировки:

```text
плохо выглядит;
улучшить форму;
лишний вес;
некрасиво;
хуже / лучше другого пользователя.
```

---

# Таймер

Перед снимком можно использовать таймер:

```text
Таймер: 5 сек

[3 сек]
[5 сек]
[10 сек]
[Без таймера]
```

Во время отсчёта:

```text
Фото через 5
Фото через 4
Фото через 3
Фото через 2
Фото через 1
```

---

# Основные действия

```text
[Сделать фото]
[Переснять]
[Следующий ракурс]
[Сохранить фото]
[Пропустить]
```

Главная кнопка зависит от состояния:

| Состояние | Главная кнопка |
| --------- | -------------- |
| Ракурс не снят | `Сделать фото` |
| Фото снято | `Следующий ракурс` |
| Все ракурсы сняты | `Сохранить фото` |
| Камера недоступна | `Пропустить` |

---

# Предпросмотр

После снимка показывается предпросмотр:

```text
Фото спереди готово

[Оставить]
[Переснять]
[Следующий ракурс]
```

Если фото размыто или пользователь вышел из кадра, Forma может мягко предложить переснять:

```text
Фото может быть недостаточно чётким.
Можно переснять, чтобы сравнение по датам было точнее.
```

---

# Завершение фотофиксации

После всех ракурсов:

```text
Фотофиксация завершена

Снято:
спереди, сбоку, сзади

Дата:
14 мая 2026

[Сохранить и продолжить]
[Переснять]
```

---

# Если экран открыт перед тренировкой

После сохранения:

```text
Фотофиксация прогресса
→ Настройка упражнения
```

Если пользователь пропустил:

```text
Фотофиксация пропущена сегодня
→ Настройка упражнения
```

Пропуск не должен блокировать тренировку, если фото не является обязательным правилом конкретного режима.

---

# Если экран открыт из профиля или прогресса

После сохранения:

```text
Фотофиксация прогресса
→ Профиль пользователя / Фото прогресса
```

или:

```text
Фотофиксация прогресса
→ Прогресс / Фото прогресса
```

---

# Если фото предлагается после тренировки

После итогового экрана:

```text
Итог тренировки
→ Фотофиксация прогресса
→ Прогресс / Фото прогресса или Главная
```

---

# Состояния экрана

## 1. Фото требуется

```text
Пора сделать фото прогресса

Последняя фотофиксация:
+7 дней назад

[Сделать сейчас]
[Напомнить после тренировки]
[Пропустить сегодня]
```

## 2. Ручной запуск

```text
Новое фото прогресса

Выберите ракурсы и сохраните фото в профиль.
```

---

## 3. Камера недоступна

```text
Камера недоступна

Проверьте подключение или пропустите этот шаг.
```

## 4. Фото сохранены

```text
Фото сохранены

```

```text
Фото пропущено

Forma напомнит позже согласно настройкам профиля.
```

# Данные экрана

```ts
type ProgressPhotoSession = {
  id: string;
  userId: string;
  createdAt: string;
  source: 'manual' | 'before_workout' | 'after_workout' | 'program_checkpoint';
  status: 'planned' | 'completed' | 'skipped' | 'failed';
  angles: ProgressPhotoAngle[];
  notes?: string;
};

type ProgressPhotoAngle = {
  angle: 'front' | 'side' | 'back';
  status: 'pending' | 'captured' | 'retake_needed' | 'skipped';
  filePath?: string;
  capturedAt?: string;
};
```

---

# Приватность

1. Фото сохраняются только в профиль текущего пользователя.
2. Фото не используются для оценки внешности.
3. Фото не показываются на главной странице.
4. Фото можно удалить из профиля.
5. Гостевой режим не сохраняет фото прогресса.
6. Если пользователь сменился, фотофиксация должна быть привязана к новому профилю только после явного выбора.

---

# Ключевые требования

1. Экран является отдельным шагом, а не блоком на главной.
2. Фото можно запускать вручную из профиля и прогресса.
3. Перед тренировкой фото можно пропустить, если оно не обязательно.
4. Формулировки должны быть нейтральными и уважительными.
5. Минимальные ракурсы: спереди, сбоку, сзади.
6. Нужно поддерживать пересъёмку каждого ракурса.
7. Нужно показывать состояние камеры.
8. Нужно сохранять дату, источник и статусы ракурсов.
9. Гостевой режим не сохраняет фото.
10. После фото экран должен вернуть пользователя в исходный сценарий.
