# Экран 14 — Завершение упражнения

## Назначение экрана

Экран **“Завершение упражнения”** появляется после выполнения всех подходов конкретного упражнения.

Он нужен, чтобы пользователь понял:

```text
Что получилось?
Нужно ли изменить нагрузку в следующий раз?
Как упражнение повлияло на тренировку?
Что делать дальше?
```

Это промежуточный экран между:

```text
Выполнение упражнения / Отдых
→ Завершение упражнения
→ Следующее упражнение / Итог тренировки
```

---

# Главная задача экрана

Экран должен показать итог одного упражнения:

* сколько подходов выполнено;
* сколько повторов выполнено;
* какой был вес;
* какой общий объём;
* насколько хорошая была амплитуда;
* какой был темп;
* были ли предупреждения;
* что Forma рекомендует на следующий раз;
* что будет следующим шагом.

---

# Когда открывается экран

Экран открывается, когда:

```text
выполнен последний подход упражнения;
пользователь вручную завершил упражнение;
упражнение было прервано;
упражнение пропущено;
завершена группа упражнений;
завершён последний шаг упражнения на время.
```

---

# Основные варианты экрана

| Состояние                           | Когда используется                          |
| ----------------------------------- | ------------------------------------------- |
| **Упражнение выполнено полностью**  | Все подходы завершены по плану.             |
| **Упражнение выполнено частично**   | Пользователь остановился раньше.            |
| **Упражнение прервано**             | Ошибка, стоп, усталость, ручное завершение. |
| **Упражнение без тренажёра**        | Отжимания, планка, растяжка.                |
| **Группа упражнений завершена**     | Чередование, суперсет, круг.                |
| **Последнее упражнение тренировки** | Далее открывается итог тренировки.          |

---

# Верхняя системная панель

Как на остальных экранах:

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод подключён]
[Правый привод подключён]
[Безопасность включена]
[СТОП]
```

Кнопка `СТОП` остаётся видимой, даже если упражнение уже завершено.

# Главный блок результата

Самый важный блок — итог упражнения.

## Для упражнения с весом

```text
Жим с пола со штангой

Выполнено:
3 из 3 подходов

Результат:
40 кг × 10
40 кг × 10
40 кг × 9

Всего:
29 повторов
Объём: 1160 кг
Средняя амплитуда: 91%
Темп: хороший
```

---

## Для собственного веса

```text
Отжимания

Выполнено:
3 из 3 подходов

Результат:
12 повторов
10 повторов
9 повторов

Всего:
31 повтор
Темп: хороший
```

---

## Для упражнения на время

```text
Планка

Выполнено:
3 из 3 подходов

Результат:
45 сек
45 сек
38 сек

Всего:
2 мин 8 сек
Стабильность: хорошая
```

# Блок “План vs факт”

Очень полезный блок.

```text
План

3 подхода
10 повторов
40 кг

Факт

3 подхода
29 повторов
40 кг

Отклонение:
-1 повтор от плана
```

Если всё выполнено:

```text
План выполнен полностью
```

Если лучше плана:

```text
+2 повтора к плану
```

Если хуже:

```text
На 3 повтора меньше плана
```

# Блок качества выполнения

Показывает техническое качество упражнения.

## Для упражнения с тренажёром

```text
Качество выполнения

Амплитуда:
91% — хорошо

Темп:
стабильный

Синхронность:
норма

Предупреждения:
нет
```

---

## Если были проблемы

```text
Качество выполнения

Амплитуда:
68% — стала короче в последнем подходе

Темп:
замедлился

Рекомендация:
в следующий раз оставить вес или снизить на 2.5 кг
```

# Блок рекомендации Forma

Это один из главных блоков.

## Вариант 1 — оставить вес

```text
Рекомендация Forma

Оставить 40 кг

Упражнение выполнено уверенно.
Амплитуда хорошая, темп стабильный.
```

---

## Вариант 2 — увеличить вес

```text
Рекомендация Forma

В следующий раз можно попробовать 42.5 кг

Все подходы выполнены уверенно,
а запас по повторениям выглядит достаточным.
```

---

## Вариант 3 — снизить вес

```text
Рекомендация Forma

В следующий раз лучше снизить до 37.5 кг

В последних повторах амплитуда стала короче,
а темп заметно замедлился.
```

---

## Вариант 4 — увеличить отдых

```text
Рекомендация Forma

Оставить вес, но увеличить отдых до 120 сек

Вес подходит, но восстановление между подходами было недостаточным.
```

# Субъективная оценка упражнения

После упражнения можно спросить:

```text
Как ощущалось упражнение?

[Легко] [Нормально] [Тяжело]
```

Можно добавить:

```text
Боль / дискомфорт?
[Нет] [Небольшой дискомфорт] [Лучше больше не предлагать]
```

Формулировки должны быть спокойные и нейтральные.
Если пользователь отмечает дискомфорт, Forma может предложить добавить упражнение в чёрный список или снизить нагрузку в будущем.

---

# Быстрая корректировка результата

Если автоподсчёт ошибся, пользователь должен поправить результат.

```text
Коррекция результата

Подход 1: 10 повторов [-] [+]
Подход 2: 10 повторов [-] [+]
Подход 3: 9 повторов [-] [+]
```

Для упражнения на время:

```text
Подход 3: 38 сек [-5 сек] [+5 сек]
```

# Блок “Что сохранить”

Экран должен явно показывать, что будет сохранено:

```text
Будет сохранено

Вес: 40 кг
Подходы: 3
Повторы: 29
Объём: 1160 кг
Средняя амплитуда: 91%
Оценка: нормально
Усталость мышц:
грудь +28
трицепс +17
передняя дельта +9
```

Прирост усталости сохраняется как события нагрузки по мышцам. Сама текущая усталость перед сохранением должна быть пересчитана по фактическому времени, чтобы выключение сервера между подходами или упражнениями не ломало восстановление.

Подробная модель описана в:

```text
docs/common/muscle-fatigue-model.md
```

Кнопка:

```text
[Сохранить результат]
```

Но лучше сохранять автоматически при переходе дальше, а кнопку сделать как подтверждение:

```text
[Сохранить и продолжить]
```

# Завершение группы упражнений

Для группы чередования показываем итог по всем шагам.

## Пример

```text

Подтягивания + Присед

Кругов:
3 из 3

Выполнено:

Круг 1:
Подтягивания ×10
Присед ×8

Круг 2:
Подтягивания ×8
Присед ×6

Круг 3:
Подтягивания ×6
Присед ×6
```

## Дальше

```text

Жим лёжа

[Перейти к следующему упражнению]
```

# Что НЕ нужно показывать

На этом экране не нужно показывать:

* полный каталог упражнений;
* всю историю тренировок;
* подробную технику;
* настройки профиля;
* сложные графики;
* глубокую диагностику;
* редактирование всей программы.

Этот экран должен быть коротким итогом одного упражнения.

# Ключевые требования

1. Экран появляется после завершения упражнения.
2. Экран показывает итог именно одного упражнения, а не всей тренировки.
3. Должен быть блок “План vs факт”.
4. Должен быть список подходов.
5. Должен быть общий объём, если упражнение с весом.
6. Должна быть средняя амплитуда, если упражнение с тренажёром.
7. Должна быть рекомендация Forma на следующий раз.
8. Пользователь может оценить сложность: легко / нормально / тяжело.
9. Пользователь может отметить дискомфорт.
10. Можно скорректировать результат, если автоподсчёт ошибся.
11. Если упражнение выполнено частично, это должно быть видно.
12. Если упражнение прервано ошибкой, это должно быть видно.
13. Если есть следующее упражнение, главный переход — к нему.
14. Если упражнение последнее, главный переход — к итогу тренировки.
15. Кнопка `СТОП` остаётся видимой.
16. Экран должен быть крупным, спокойным, понятным и удобным для 4K-монитора.
