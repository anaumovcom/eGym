    ````md
# Экран 3 — Главная страница

## Назначение экрана

Главная страница — основной экран приложения **Forma** после выбора пользователя.

Это не просто дашборд со статистикой.  
Это **командный центр тренировки**, который должен быстро ответить пользователю:

1. Можно ли сегодня тренироваться?
2. Что лучше тренировать сегодня?
3. Какие мышцы устали, а какие готовы?
4. Какая тренировка запланирована?
5. Можно ли безопасно запускать тренажёр?
6. Как быстро начать упражнение?

Главная страница должна вести пользователя к действию:

```text
Начать сегодняшнюю тренировку
````

или:

```text
Быстрый старт
```

---

# Главное правило экрана

Главная страница должна показывать:

```text
Что делать сегодня и почему именно это.
```

Пример смыслового сообщения:

```text
Алексей, сегодня лучше сделать тренировку на спину и бицепс.

Грудь и трицепс ещё восстанавливаются после прошлой тренировки.
Спина и ноги готовы к нагрузке.
Тренажёр готов.
Можно начинать.
```

---

# Что НЕ должно быть на главной

На главной странице не должно быть:

* блока фото прогресса;
* запроса сделать фото;
* полной истории тренировок;
* полного каталога упражнений;
* редактора программы;
* подробных графиков прогресса;
* настроек профиля;
* настроек ШВП;
* диагностики приводов в полном виде;
* длинных таблиц.

Фото прогресса должно появляться **автоматически перед началом тренировки**, если пришло время сделать фото.

---

# Общая структура экрана

Экран состоит из следующих зон:

1. Верхняя системная панель.
2. Левое вертикальное меню.
3. Главный блок рекомендации.
4. Карточка сегодняшней тренировки.
5. Карточка статуса тренажёра.
6. Подробная карта усталости мышц.
7. Блок рекомендованных упражнений.
8. Блок быстрого старта.
9. Краткий прогресс.

---

# Верхняя системная панель

## Состав

```text
Forma  [Алексей]  [Тренажёр готов]  [Левый привод: подключён]  [Правый привод: подключён]  [СТОП]
```

## Элементы

| Элемент                      | Назначение                         |
| ---------------------------- | ---------------------------------- |
| **Forma**                    | Логотип и название приложения.     |
| **Алексей**                  | Текущий активный пользователь.     |
| **Тренажёр готов**           | Общий статус системы.              |
| **Левый привод: подключён**  | Статус левого привода.             |
| **Правый привод: подключён** | Статус правого привода.            |
| **СТОП**                     | Аварийная остановка. Всегда видна. |

## Поведение кнопки `СТОП`

При нажатии:

* движение приводов блокируется;
* тренажёр переходит в безопасное состояние;
* запуск упражнений становится недоступен;
* появляется сообщение о блокировке.

Пример сообщения:

```text
Аварийная остановка активна

Движение приводов заблокировано.
Проверьте тренажёр и разблокируйте систему.
```

# Главный блок рекомендации

## Назначение

Это главный смысловой блок экрана.

Он показывает:

* приветствие;
* готовность пользователя;
* главную рекомендацию;
* краткое объяснение;
* основные действия.

## Содержимое

```text
Добрый день, Алексей

Готовность: 78%

Сегодня лучше: Спина + бицепс

Грудь и трицепс ещё восстанавливаются после прошлой тренировки.
Ноги готовы к умеренной нагрузке.

[Начать сегодняшнюю тренировку]
[Быстрый старт]
```

## Готовность

Готовность отображается крупным круговым индикатором.

Пример:

```text
Готовность
78%
```

## Цветовая логика готовности

| Значение | Цвет                    | Смысл                                       |
| -------- | ----------------------- | ------------------------------------------- |
| 80–100%  | зелёный                 | можно тренироваться полноценно              |
| 60–79%   | жёлто-зелёный / золотой | можно тренироваться, но учитывать усталость |
| 30–59%   | оранжевый               | лучше лёгкая тренировка                     |
| 0–29%    | красный                 | лучше восстановление                        |

Для текущего примера:

```text
78% — тренироваться можно, но грудь и трицепс лучше не перегружать.
```

# Основная кнопка действия

Главная кнопка:

```text
Начать сегодняшнюю тренировку
```

## Поведение

При нажатии запускается сценарий:

```text
Главная
→ Проверка необходимости фото прогресса
→ Если нужно: Фотофиксация прогресса
→ Предстартовая проверка
→ Карточка первого упражнения
→ Калибровка упражнения
→ Выполнение упражнения
```

Если фото прогресса сейчас не требуется:

```text
Главная
→ Предстартовая проверка
→ Карточка первого упражнения
→ Калибровка упражнения
→ Выполнение упражнения
```

# Карточка “Сегодняшняя тренировка”

## Назначение

Показывает тренировку, запланированную на сегодня.

## Содержимое

```text
Сегодняшняя тренировка

Спина + бицепс

5 упражнений
18 подходов
≈ 45 минут

1. Тяга сверху
2. Тяга к поясу
3. Сгибание рук
4. Тяга прямыми руками
5. Планка

[Начать]
[Открыть план]
```

## Что показывать

| Поле                   | Пример              |
| ---------------------- | ------------------- |
| Название тренировки    | Спина + бицепс      |
| Количество упражнений  | 5 упражнений        |
| Количество подходов    | 18 подходов         |
| Примерная длительность | ≈ 45 минут          |
| Список упражнений      | первые 5 упражнений |
| Основное действие      | Начать              |
| Вторичное действие     | Открыть план        |

## Поведение кнопки `Начать`

То же, что и у главной кнопки `Начать сегодняшнюю тренировку`.

# Карточка “Статус тренажёра”

## Назначение

Показывает, можно ли запускать упражнения.

## Содержимое

```text
Статус тренажёра

Готов к работе

Левый привод: подключён
Правый привод: подключён
Система безопасности: включена
Калибровка: перед упражнением

[Диагностика]
```

## Важное правило

Если тренажёр не готов, кнопки запуска тренировки должны быть недоступны.

---

## Возможные состояния

### 1. Всё готово

```text
Готов к работе

Левый привод: подключён
Правый привод: подключён
Система безопасности: включена
Калибровка: перед упражнением
```

---

### 2. Нет связи с приводом

```text
Запуск упражнений недоступен.

[Повторить подключение]

```

```text
Аварийная остановка активна
```

# Подробная карта усталости мышц

## Назначение

Это один из главных блоков главной страницы.

Карта должна быть **подробной**, а не краткой.
Она должна показывать состояние большинства основных мышечных групп прямо на главной.

---

## Содержимое блока

```text
Подробная карта усталости мышц

[Тело спереди] [Тело сзади]

Легенда:
зелёный — готова к нагрузке
жёлтый — лёгкая усталость
оранжевый — умеренная усталость
красный — высокая усталость / избегать нагрузки
серый — нет данных

[Открыть экран усталости]
```

---

## Мышцы, которые нужно отображать

### Передняя сторона

```text
Грудь
Передние дельты
Средние дельты
Бицепс
Предплечья
Пресс
Косые мышцы живота
Квадрицепсы
Икры
```

### Задняя сторона

```text
Трапеции
Задние дельты
Трицепс
Широчайшие
Разгибатели спины
Ягодицы
Бицепс бедра
Икры
```

---

## Цветовая логика

| Цвет      | Состояние           | Значение                   |
| --------- | ------------------- | -------------------------- |
| Зелёный   | Готова к нагрузке   | Можно тренировать          |
| Жёлтый    | Лёгкая усталость    | Можно тренировать умеренно |
| Оранжевый | Умеренная усталость | Нагрузку лучше снизить     |
| Красный   | Высокая усталость   | Лучше не нагружать         |
| Серый     | Нет данных          | Нет информации             |

---

## Пример статусов мышц

```text
Грудь — высокая усталость
Трицепс — средняя усталость
```

Переход на отдельный экран:


Там можно показать:

* какие упражнения повлияли на усталость;
* когда мышца будет готова;
* рекомендации по восстановлению.

# Блок “Рекомендовано сегодня”

## Назначение

Показывает упражнения, которые подходят сегодня с учётом:

* целей пользователя;
* усталости мышц;
* чёрного списка упражнений;
* последней тренировки;
* доступного оборудования;
* запланированной тренировки.

## Содержимое

```text
Рекомендовано сегодня

Тяга сверху
Спина, бицепс
Рекомендуется

Тяга к поясу
Спина
Рекомендуется

Сгибание рук
Бицепс
Можно выполнить

[Открыть каталог]
```

## Правила

Упражнения из чёрного списка пользователя не должны попадать в этот блок.

---

# Блок “Быстрый старт”

## Назначение

Позволяет быстро начать упражнение без открытия каталога или календаря.

## Содержимое

```text
Быстрый старт

Жим лёжа
40 кг × 10 × 3
2 дня назад

Присед
60 кг × 10 × 3
3 дня назад

Тяга сверху
45 кг × 10 × 3
5 дней назад

[Выбрать упражнение]
```

## Логика показа упражнений

Показывать:

* последние выполненные упражнения;
* часто используемые упражнения;
* упражнения, которые можно безопасно выполнить сегодня;
* упражнения, связанные с текущей целью.

Если упражнение нагружает уставшие мышцы, нужно показать предупреждение.

Пример:

```text
Жим лёжа

Грудь ещё восстанавливается.
Лучше снизить нагрузку или выбрать другое упражнение.
```

# Блок “Краткий прогресс”

## Назначение

Показывает краткую мотивационную сводку без перегруза графиками.

## Содержимое

```text
Краткий прогресс

8 тренировок за месяц
3 недели подряд
+4% к объёму за неделю
-1.2 кг за месяц

[Открыть прогресс]
```

## Что можно показывать

| Показатель          | Пример                     |
| ------------------- | -------------------------- |
| Тренировок за месяц | 8                          |
| Серия регулярности  | 3 недели подряд            |
| Объём за неделю     | +4%                        |
| Вес за месяц        | -1.2 кг                    |
| Личный рекорд       | новый рекорд в тяге сверху |

# Фото прогресса

## Важно

На главной странице блока фото прогресса **нет**.

Фотофиксация появляется автоматически **перед началом тренировки**, если пришло время сделать фото.

---

## Логика автоматического появления

Экран фотофиксации показывается перед тренировкой, если:

```text
Фото ещё ни разу не делали
или прошло заданное количество дней с последнего фото
или начался новый тренировочный цикл
или пользователь включил регулярную фотофиксацию
```

---

## Сценарий

```text
Пользователь нажимает “Начать тренировку”
→ Forma проверяет дату последнего фото
→ Если фото нужно обновить
→ Открывается экран “Фотофиксация прогресса”
→ После фото пользователь переходит к предстартовой проверке
```

---

## Варианты действий на экране фотофиксации

```text
[Сделать фото]
[Пропустить сегодня]
[Больше не напоминать в этом цикле]
```

# Ключевые требования

1. Экран должен быть рассчитан на большой 4K-монитор.
2. Интерфейс должен продолжать стиль Forma: тёмный фон, золотые акценты, зелёные статусы, красный `СТОП`.
3. Главная страница должна быть центром принятия решения перед тренировкой.
4. Подробная карта усталости мышц должна быть крупным центральным блоком.
5. На карте должны отображаться мышцы спереди и сзади.
6. Фото прогресса не должно отображаться на главной странице.
7. Фото прогресса появляется отдельным автоматическим шагом перед тренировкой.
8. Если тренажёр не готов, запуск тренировки должен быть заблокирован.
9. Рекомендации должны объяснять, почему сегодня выбрана именно эта тренировка.
10. Упражнения из чёрного списка не должны попадать в рекомендации.
11. Основная кнопка действия должна быть очевидной.
12. Быстрый старт должен быть доступен всегда, если тренажёр готов.
13. Главная не должна быть перегружена настройками и длинной аналитикой.
14. Все элементы должны быть крупными и удобными для сенсорного управления.
15. Экран должен выглядеть как премиальная панель управления умным тренажёром.
