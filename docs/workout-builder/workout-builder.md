````md
# Экран 7 — Конструктор тренировок

## Назначение экрана

Экран **“Конструктор тренировок”** нужен для создания, редактирования и сохранения тренировочных программ в приложении **Forma**.

Главная задача экрана:

```text
Собрать тренировку из упражнений,
настроить нагрузку, подходы, повторы, отдых,
при необходимости объединить упражнения в группы,
и сохранить программу для дальнейшего использования.
````

Этот экран отвечает за **структуру тренировки**, но не отвечает за выполнение упражнений и не отвечает за настройки железа.

---

# Главное правило экрана

```text
Конструктор тренировок = создание шаблона тренировки.
Календарь = назначение тренировки на дату.
Сегодняшняя тренировка = выполнение плана на сегодня.
Калибровка = настройка амплитуды перед конкретным упражнением.
Настройки тренажёра = безопасность, приводы, ШВП, лимиты.
```

---

# Что можно делать на этом экране

На экране можно:

* создать новую тренировку;
* отредактировать существующую тренировку;
* сгенерировать тренировку автоматически;
* открыть список своих программ;
* добавить упражнение из каталога;
* добавить группу упражнений;
* чередовать упражнения;
* настроить вес, подходы, повторы и отдых;
* выбрать режим нагрузки;
* выбрать темп выполнения;
* добавить комментарий к упражнению;
* изменить порядок упражнений;
* заменить упражнение;
* удалить упражнение;
* сохранить программу;
* сохранить программу как копию;
* назначить программу в календарь;
* посмотреть сводку тренировки;
* посмотреть баланс мышц;
* увидеть предупреждения по тренировке.

---

# Что НЕ должно быть на этом экране

В конструкторе не должно быть:

* настройки высоты грифа;
* калибровки нижней и верхней точки;
* настройки ШВП;
* настройки сервоприводов;
* настройки аварийных лимитов;
* детальной диагностики тренажёра;
* выполнения упражнения;
* фото прогресса;
* подробной статистики прогресса.

Высота грифа и амплитуда зависят от конкретного упражнения и задаются позже — на экране **“Калибровка упражнения”**.


## Пример


## Важное поведение

Поля должны быть редактируемыми.
Изменения не должны сохраняться автоматически без явного действия пользователя.

# Группа упражнений

В конструкторе обязательно должна быть возможность создать **группу упражнений**.

Группа нужна, когда упражнения выполняются не классическим способом “сначала все подходы одного упражнения, потом другое”, а по особой схеме.

## Типы групп

```text
Обычный блок
Чередование
Суперсет
Круг
```

---

# Группа чередования

## Назначение

Группа чередования позволяет выполнять упражнения по очереди.

Пример:

```text
Подтянулся ×10
Поприседал ×8
Подтянулся ×8
Поприседал ×6
Подтянулся ×6
Поприседал ×6
```

То есть порядок строится не по упражнениям, а по конкретным подходам.

---

## Как отображается группа в плане

```text
1. Группа чередования

Подтягивания + Присед

3 круга · 6 подходов · ≈12 минут

Круг 1:
Подтягивания ×10
Присед ×8

Круг 2:
Подтягивания ×8
Присед ×6

Круг 3:
Подтягивания ×6
Присед ×6
```

---

## Что должно быть видно у группы

| Поле                     | Пример                                        |
| ------------------------ | --------------------------------------------- |
| Тип группы               | Группа чередования                            |
| Название                 | Подтягивания + Присед                         |
| Количество кругов        | 3                                             |
| Количество подходов      | 6                                             |
| Отдых между упражнениями | 30 сек                                        |
| Отдых между кругами      | 90 сек                                        |
| Список подходов          | Подтягивания, присед, подтягивания, присед    |
| Действия                 | Редактировать, свернуть, удалить, переместить |

---

# Суперсет

## Назначение

Суперсет — это выполнение двух упражнений почти без отдыха между ними.

```text
Подтягивания
сразу Присед
отдых 90 сек
повторить
```

## Отличие от чередования

| Тип             | Логика                                                 |
| --------------- | ------------------------------------------------------ |
| **Чередование** | Между упражнениями может быть отдых.                   |
| **Суперсет**    | Упражнения выполняются почти подряд, отдых после пары. |

---

# Круг

## Назначение

Круг — это несколько упражнений подряд, затем отдых.

Пример:

```text
Подтягивания
Присед
Отжимания
Планка
отдых 2 минуты
повторить 3 круга
```

# Баланс мышц

Блок **“Баланс мышц”** показывает, какие группы будут нагружены.

## Пример

```text
Спина — высокая нагрузка
Бицепс — средняя нагрузка
Ноги — средняя нагрузка
Предплечья — лёгкая нагрузка
Кор — лёгкая нагрузка
Грудь — не нагружается
Плечи — не нагружаются
```

## Визуально

Можно использовать:

* SVG-человека спереди и сзади;
* цветные зоны мышц;
* список мышц;
* цветные метки нагрузки.

---

# Предупреждения

В правой нижней части экрана есть блок **“Предупреждения”**.

## Пример предупреждений

```text
Длинная тренировка
Расчётное время больше цели на 10 минут.
Рекомендация: сократить количество подходов.

Короткий отдых
Для тяжёлых подходов рекомендуется отдых 60–90 сек.

Упражнения из чёрного списка
В этой тренировке отсутствуют.
```

---

# Типы предупреждений

| Тип                          | Пример                                   |
| ---------------------------- | ---------------------------------------- |
| Длинная тренировка           | Расчётное время больше целевого.         |
| Перегруз мышцы               | Слишком много упражнений на одну группу. |
| Короткий отдых               | Отдых слишком мал для тяжёлых подходов.  |
| Упражнение из чёрного списка | Добавлено вручную.                       |
| Резкий рост нагрузки         | Вес сильно выше прошлого результата.     |
| Не заполнены параметры       | Нет повторов или отдыха.                 |

---

# Работа с чёрным списком упражнений

## Правило

```text
Автогенерация не использует упражнения из чёрного списка.
Ручное добавление возможно, но только с предупреждением.
```

## Если упражнение в чёрном списке

```text
Это упражнение находится в чёрном списке пользователя.
Оно не будет предлагаться автоматически.

[Добавить вручную]
[Отмена]
```

---

# Работа с усталостью мышц

Конструктор может показывать текущую усталость, но не должен запрещать создание программы.

Причина:

```text
Пользователь может создавать программу на будущее.
Усталость изменится к моменту выполнения.
```

Если тренировка тяжёлая для текущего дня:

```text
Если назначить эту тренировку на сегодня,
Forma рекомендует снизить нагрузку на грудь.
```

---

# Работа с калибровкой

В конструкторе не выполняется калибровка.

Можно показывать только информационную подсказку:

```text
Калибровка будет выполнена перед упражнением.
```

Не хранить в конструкторе:

```text
нижнюю точку;
верхнюю точку;
минимальную безопасную высоту;
максимальную безопасную высоту;
положение грифа.
```

# Сценарий: создание тренировки с чередованием

## Шаги

```text
1. Пользователь открывает Конструктор.
2. Нажимает “Новая тренировка”.
3. Вводит название “День спины”.
4. Нажимает “Добавить группу”.
5. Выбирает тип “Чередование”.
6. Добавляет упражнения “Подтягивания” и “Присед”.
7. Указывает 3 круга.
8. Заполняет повторы:
   - Подтягивания: 10 / 8 / 6
   - Присед: 8 / 6 / 6
9. Указывает отдых:
   - между упражнениями 30 сек
   - между кругами 90 сек
10. Нажимает “Применить изменения”.
11. Добавляет остальные упражнения.
12. Проверяет сводку и баланс мышц.
13. Нажимает “Сохранить программу”.
```

```text
Группа: Подтягивания + Присед

Сейчас:
Подтягивания ×10

Присед ×8
```

# Ключевые требования

1. Экран должен быть рассчитан на большой 4K-монитор.
2. Конструктор создаёт шаблоны тренировок.
3. Назначение тренировки на дату происходит через календарь.
4. В конструкторе нет настройки высоты грифа.
5. В конструкторе нет калибровки упражнения.
6. В конструкторе нет настроек ШВП и сервоприводов.
7. Можно добавлять отдельные упражнения.
8. Можно создавать группы упражнений.
9. Группы могут быть обычными, чередованием, суперсетом или кругом.
10. Должна быть возможность чередовать подходы разных упражнений.
11. Пример: подтягивания ×10 → присед ×8 → подтягивания ×8 → присед ×6.
12. Для групп нужна таблица подходов по кругам.
13. Можно задавать отдых между упражнениями и отдых между кругами.
14. Можно редактировать вес, подходы, повторы, отдых, режим нагрузки и темп.
15. Можно менять порядок упражнений и групп.
16. Можно удалять и заменять упражнения.
17. Можно видеть сводку тренировки.
18. Можно видеть баланс мышц.
19. Должны быть предупреждения о слишком длинной тренировке, коротком отдыхе и перекосе нагрузки.
20. Упражнения из чёрного списка не участвуют в автогенерации.
21. Ручное добавление упражнения из чёрного списка возможно только с предупреждением.
22. После сохранения программу можно назначить в календарь.
23. Интерфейс должен быть красивым, крупным и удобным для сенсорного управления.
