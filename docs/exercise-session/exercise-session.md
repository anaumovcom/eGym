# Экран 12 — Выполнение упражнения

## Назначение экрана

Экран **“Выполнение упражнения”** — главный live-экран во время подхода.

Его задача:

```text
Показать пользователю, что делать прямо сейчас:
сколько повторов выполнено,
какой сейчас подход,
какая нагрузка,
правильная ли амплитуда,
какой темп,
и безопасно ли продолжается движение.
```

На этом экране не должно быть лишних настроек.
Пользователь уже начал упражнение, поэтому интерфейс должен быть максимально крупным, понятным и спокойным.

---

# Главное правило экрана

```text
Во время выполнения упражнения нельзя перегружать пользователя информацией.
```

На первом плане должны быть:

1. **Текущий подход**
2. **Количество повторов**
3. **Нагрузка**
4. **Темп**
5. **Амплитуда**
6. **Положение грифа / движение**
7. **СТОП**
8. **Пауза / завершить подход**

---

# Основные варианты экрана

Экран должен поддерживать разные типы упражнений:

| Тип упражнения            | Что показывать                                                       |
| ------------------------- | -------------------------------------------------------------------- |
| **С тренажёром и грифом** | Повторы, вес, положение грифа, амплитуда, темп, синхронность сторон. |
| **Собственный вес**       | Повторы, подход, темп, видео/анимация, таймер отдыха.                |
| **Упражнение на время**   | Таймер, удержание, подход, оставшееся время.                         |
| **Растяжка**              | Таймер, сторона тела, мягкие подсказки, дыхание.                     |
| **Группа / чередование**  | Текущее упражнение, круг, следующий шаг.                             |

---

# Верхняя системная панель

Верхняя панель остаётся, но должна быть компактнее, чем на других экранах.

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод]
[Правый привод]
[СТОП]
```

Кнопка **СТОП** должна быть самой заметной кнопкой на экране.

# Блок 1 — Информация об упражнении

В верхней части основного контента:

```text
Жим с пола со штангой
Barbell Floor Press

Подход 1 из 3
40 кг
Цель: 10 повторов
Отдых после подхода: 90 сек
```

Если упражнение входит в тренировку:

```text
Упражнение 1 из 5
Подход 1 из 3
```

Если это группа чередования:

```text
Группа: Подтягивания + Присед
Круг 2 из 3
Шаг 3 из 6
Сейчас: Подтягивания ×8
Дальше: Присед ×6
```

---

# Блок 2 — Видео / анимация упражнения

Слева или в центре должен быть большой визуальный блок.

## Для обычного упражнения

```text
[Видео упражнения 16:9]
```

Видео можно показывать:

* в зацикленном режиме;
* без звука;
* с выбранной моделью: мужчина / женщина;
* с выбранным ракурсом: сбоку / спереди.

## Во время подхода

Видео не должно отвлекать.
Оно должно быть скорее визуальной подсказкой, чем главным элементом.

Можно сделать режимы:

```text
[Видео]
[Схема движения]
[Минимальный режим]
```

---

# Блок 3 — Повторы

Это один из самых крупных элементов.

```text
Повторы

7 / 10
```

## Варианты отображения

### До начала подхода

```text
0 / 10

Начните движение
```

### Во время выполнения

```text
7 / 10

Хороший темп
```

### Цель достигнута

```text
10 / 10

Цель подхода выполнена
```

### Пользователь сделал больше

```text
12 / 10

Дополнительные повторы
```

# Блок 4 — Текущий подход

```text
Подход 1 из 3
```

Дополнительно:

```text
Осталось подходов: 2
Следующий отдых: 90 сек
```

Если подходй последний:

```text
Последний подход
```

---

# Блок 5 — Нагрузка

Для упражнения с тренажёром:

```text
Нагрузка

40 кг
Обычный вес
```

Если режим другой:

```text
Режим: помощь вверх
Режим: негативная фаза
Режим: лёгкий режим
```

Для собственного веса:

```text
Собственный вес
```

Для растяжки:

```text
Интенсивность: лёгкая
```

---

# Блок 6 — Положение грифа

Для упражнений, где тренажёр управляет грифом, нужен live-индикатор.

```text
Положение грифа

Текущая позиция: 86 см
Нижняя точка: 64 см
Верхняя точка: 132 см
```

## Визуально

```text
132 см ┤ Верхняя точка
       │
       │     ● текущая позиция
       │
64 см  ┤ Нижняя точка
```

Показываем:

* текущую позицию;
* нижнюю точку;
* верхнюю точку;
* рабочий диапазон;
* выход за диапазон, если случился;
* левую/правую сторону, если нужно.

---

# Блок 7 — Амплитуда

Очень важный показатель.

```text
Амплитуда

92%
```

## Цветовая логика

| Амплитуда | Отображение                 |
| --------- | --------------------------- |
| 90–100%   | Хорошо                      |
| 70–89%    | Нормально                   |
| 50–69%    | Неполная амплитуда          |
| <50%      | Повтор может не засчитаться |

Пример:

```text
Амплитуда: 92%
Повтор засчитан
```

Или:

```text
Амплитуда: 58%
Повтор слишком короткий
```

---

# Блок 8 — Темп выполнения

Темп должен быть простым и понятным.

```text
Темп

Хорошо
```

Варианты:

```text
Слишком быстро
Хорошо
Слишком медленно
Пауза
```

Можно показывать визуальный метроном:

```text
Опускайте
Пауза
Поднимайте
```

Или короткую шкалу:

```text
Темп: 2 сек вниз · 1 сек вверх
```

---

# Блок 9 — Подсказки во время выполнения

Подсказки должны быть короткими.

Примеры:

```text
Держите локти ближе к корпусу
Не торопитесь вниз
Хорошая амплитуда
Повтор засчитан
Слишком короткое движение
```

Важно: не показывать длинные инструкции во время подхода.

---

# Блок 10 — Синхронность сторон

Для тренажёра с двумя сторонами можно показывать компактно:

```text
Синхронность

Левая: 86.2 см
Правая: 86.0 см
Разница: 0.2 см
```

Если всё нормально:

```text
Синхронность: норма
```

Если есть проблема:

```text
Внимание: рассинхрон сторон
```

При критической ошибке:

```text
Движение остановлено
Откройте диагностику
```

# Основные кнопки управления

На экране должны быть крупные кнопки:

```text
[Пауза]
[Завершить подход]
[СТОП]
```

## Пауза

Приостанавливает подход.

```text
Пауза

[Продолжить]
[Завершить подход]
[Завершить упражнение]
```

## Завершить подход

Переход на экран отдыха между подходами.

```text
Подход завершён
→ Отдых между подходами
```

## СТОП

Экстренная остановка.

```text
СТОП
```

Должна быть:

* крупная;
* красная;
* всегда доступная;
* не рядом с обычными вторичными кнопками, чтобы её не перепутать.

# Экран для упражнения без тренажёра

Например, отжимания.

```text
Отжимания

Подход 1 из 3
Цель: 12 повторов

Повторы
8 / 12

[Видео 16:9]

Темп: хорошо
Амплитуда: по камере / вручную / не отслеживается

[+ Повтор]
[- Повтор]
[Завершить подход]
```

Если автоматического подсчёта нет, нужна ручная корректировка:

```text
[+1]
[-1]
```

# Отображение прогресса упражнения

Нужно показывать прогресс не только текущего подхода, но и всего упражнения.

```text
Упражнение

Подход 1: выполняется
Подход 2: далее
Подход 3: далее
```

Или компактно:

```text
● ○ ○
```

После первого подхода:

```text
✓ ● ○
```

---

# Сравнение с прошлым разом

Небольшой блок, не отвлекающий:

```text
Прошлый раз:
40 кг × 10 × 3

Сегодня:
подход 1 из 3
```

После подхода:

```text
Так же, как в прошлый раз
```

Или:

```text
+2 повтора к прошлому первому подходу
```

# Live-метрики

Для упражнения с тренажёром можно показывать:

```text
Положение грифа
Амплитуда
Темп
Синхронность сторон
Текущая нагрузка
```

Но не нужно показывать слишком много технических значений одновременно.

Лучше сделать компактный блок:

```text
Движение

Амплитуда: 92%
Темп: хорошо
Синхронность: норма
```

---

# Что НЕ нужно показывать на этом экране

Не нужно показывать:

* длинную технику;
* полный каталог;
* настройки профиля;
* календарь;
* сложные графики;
* подробные параметры ШВП;
* большие таблицы;
* редактирование программы.

---

# Переход после подхода

Когда подход завершён:

```text
Выполнение упражнения
→ Отдых между подходами
```

Если это был последний подход упражнения:

```text
Выполнение упражнения
→ Завершение упражнения
```

Если это часть тренировки:

```text
Завершение упражнения
→ Следующее упражнение
```

# Ключевые требования

1. Экран должен быть максимально крупным и понятным.
2. Главный фокус — текущий подход и повторы.
3. Кнопка `СТОП` всегда видна.
4. Для упражнений с тренажёром показывать положение грифа и амплитуду.
5. Для упражнений без тренажёра не показывать технические данные грифа.
6. Для упражнений на время показывать крупный таймер.
7. Для растяжки показывать таймер и мягкие подсказки.
8. Для групп чередования показывать круг, шаг и следующее упражнение.
9. Должна быть кнопка `Пауза`.
10. Должна быть кнопка `Завершить подход`.
11. Повторы должны считаться автоматически, если доступно.
12. Если автоподсчёт недоступен, нужны кнопки `+1` и `-1`.
13. Неполная амплитуда должна отображаться понятно.
14. После подхода переходить на экран отдыха.
15. После последнего подхода переходить на экран завершения упражнения.
16. Интерфейс должен быть удобен для большого 4K-монитора и чтения с расстояния.
