# Экран — Прогресс

## Назначение экрана

Экран **“Прогресс”** нужен, чтобы пользователь видел, как меняются его результаты со временем:

```text
Становлюсь ли я сильнее?
Регулярно ли тренируюсь?
По каким упражнениям есть рост?
Какие мышцы тренируются чаще всего?
Как меняются вес, замеры и фотофиксация?
Что Forma рекомендует дальше?
```

Важно: экран не должен оценивать внешность пользователя или сравнивать его с другими.
Он должен показывать **личную динамику относительно самого себя**.

---

# Главная идея экрана

Экран должен быть аналитическим центром:

```text
Прогресс = тренировки + упражнения + тело + фото + регулярность + достижения
```

Но без перегруза. На первом уровне показываем краткую сводку, а подробности — во вкладках.

---

# Основные вкладки экрана

Я бы сделал 7 вкладок:

| № | Вкладка            | Назначение                                      |
| - | ------------------ | ----------------------------------------------- |
| 1 | **Сводка**         | Главные показатели за выбранный период.         |
| 2 | **Упражнения**     | Прогресс по конкретным упражнениям.             |
| 3 | **Сила и объём**   | Рабочие веса, общий объём, повторы, подходы.    |
| 4 | **Регулярность**   | Календарь активности, серии, пропуски, частота. |
| 5 | **Мышцы**          | Какие мышечные группы получали нагрузку.        |
| 6 | **Тело**           | Вес, замеры, данные с весов.                    |
| 7 | **Фото прогресса** | Фотофиксации и сравнение по датам.              |

# Переключатель периода

Вверху экрана нужен выбор периода:

```text
[7 дней] [30 дней] [3 месяца] [6 месяцев] [Год] [Всё время]
```

По умолчанию:

```text
30 дней
```

Также полезен выбор диапазона дат:

```text
12 апреля — 12 мая
```

# Вкладка 1 — Сводка

## Назначение

Показать главную картину за выбранный период.

## Главные карточки

```text
8 тренировок
за 30 дней

142 подхода
выполнено

1 284 повтора
всего

42 600 кг
общий объём

3 недели
серия регулярности

+4%
к объёму за месяц
```

---

## Блок “Главный прогресс”

```text
Главный прогресс

Лучший рост:
Тяга сверху

Было:
35 кг × 10 × 3

Стало:
45 кг × 10 × 3

Изменение:
+10 кг к рабочему весу
```

---

## Блок “Что стало лучше”

```text
Что стало лучше

- вырос рабочий вес в тяге сверху;
- тренировки стали регулярнее;
- средняя амплитуда в жимах стала стабильнее;
- общий объём за неделю вырос на 4%.
```

---

## Блок “Рекомендация Forma”

```text
Рекомендация Forma

Прогресс идёт стабильно.
На следующей неделе можно немного увеличить нагрузку в упражнениях на спину,
но оставить грудь без резкого повышения веса.
```

# Вкладка 2 — Упражнения

## Назначение

Показать прогресс по конкретному упражнению.

## Основные элементы

```text
Выберите упражнение:
[Тяга сверху ▼]
```

После выбора:

```text
Тяга сверху

Последний результат:
45 кг × 10 × 3

Лучший результат:
50 кг × 8

Лучший объём:
1 500 кг

Выполнений:
8 раз
```

---

## Графики по упражнению

Для выбранного упражнения можно показывать:

| График          | Что показывает                    |
| --------------- | --------------------------------- |
| **Рабочий вес** | Как менялся вес.                  |
| **Повторы**     | Сколько повторов выполнялось.     |
| **Объём**       | Вес × повторы × подходы.          |
| **Амплитуда**   | Качество движения, если доступно. |
| **Темп**        | Стабильность выполнения.          |

---

## Пример блока

```text
Динамика рабочего веса

12 апреля — 35 кг
19 апреля — 37.5 кг
26 апреля — 40 кг
3 мая — 42.5 кг
10 мая — 45 кг
```

---

## Таблица истории упражнения

```text
Дата        Вес      Подходы   Повторы   Объём     Амплитуда
10 мая      45 кг    3         30        1350 кг   93%
3 мая       42.5 кг  3         30        1275 кг   91%
26 апреля   40 кг    3         28        1120 кг   90%
```

# Вкладка 4 — Регулярность

## Назначение

Показать тренировочную привычку и распределение занятий.

## Основные блоки

```text
Тренировок за месяц:
8

Средняя частота:
2 раза в неделю

Серия:
3 недели подряд

Пропущено:
1 запланированная тренировка
```

---

## Календарь активности

Можно показать мини-календарь:

```text
Пн Вт Ср Чт Пт Сб Вс

●  ○  ●  ○  ○  ●  ○
○  ●  ○  ○  ●  ○  ○
```

Где:

| Обозначение     | Значение                      |
| --------------- | ----------------------------- |
| Зелёная точка   | тренировка выполнена          |
| Жёлтая точка    | тренировка частично выполнена |
| Серая точка     | день отдыха                   |
| Оранжевая точка | пропущенная тренировка        |

---

## Блок рекомендации

```text
Регулярность хорошая

Вы стабильно тренируетесь 2 раза в неделю.
Если хотите быстрее продвигаться, можно добавить короткую лёгкую тренировку.
```

# Вкладка 5 — Мышцы

## Назначение

Показать, какие мышцы получали нагрузку за выбранный период.

## Визуализация

Большая SVG-карта тела:

```text
[Тело спереди] [Тело сзади]
```

Цвета показывают объём нагрузки:

| Цвет      | Значение               |
| --------- | ---------------------- |
| Серый     | почти не нагружалась   |
| Зелёный   | лёгкая нагрузка        |
| Жёлтый    | средняя нагрузка       |
| Оранжевый | высокая нагрузка       |
| Красный   | очень высокая нагрузка |

---

## Список мышц

```text
Спина — высокая нагрузка
Бицепс — высокая нагрузка
Грудь — средняя нагрузка
Ноги — средняя нагрузка
Плечи — лёгкая нагрузка
Кор — лёгкая нагрузка
```

---

## Баланс мышечных групп

```text
Баланс нагрузки

Спина: высокая
Грудь: средняя
Ноги: средняя
Плечи: низкая

Рекомендация:
```

# Вкладка 6 — Тело

## Назначение

Показать изменения веса и замеров.

Важно: формулировки должны быть нейтральными.
Не “лучше/хуже тело”, а “изменение параметров”.

---

## Основные показатели

```text
Вес:
92.4 кг

Изменение за месяц:
-1.2 кг

Талия:
97 см

Изменение:
-1 см

Последнее измерение:
12 мая
```

---

## Графики

```text
Вес по датам
Талия по датам
Грудь / бёдра / плечи / бицепс
```

---

## Источник данных

```text
Источник:
умные весы не подключены

[Подключить устройство]
[Ввести вручную]
```

Если весы подключены:

```text
Умные весы подключены
Последняя синхронизация: сегодня, 08:40
```

# Вкладка 7 — Фото прогресса

## Назначение

Показывать фотофиксации пользователя по датам.

Важно: экран не должен оценивать внешность.
Только сравнение дат, позы, освещения и фиксация изменений.

---

## Основные блоки

```text
Последняя фотофиксация:
12 мая

Ракурсы:
спереди, сбоку, сзади

Следующая фотофиксация:
через 7 дней
```

---

## Галерея

```text
12 мая
[спереди] [сбоку] [сзади]

1 мая
[спереди] [сбоку] [сзади]

20 апреля
[спереди] [сбоку] [сзади]
```

---

## Сравнение фото

```text
Сравнить:

[1 мая] → [12 мая]

Ракурс:
[Спереди] [Сбоку] [Сзади]
```

---

## Действия

```text
[Сделать новое фото]
[Сравнить фото]
[Открыть галерею]
```

При нажатии `Сделать новое фото` открывается отдельный экран:

```text
Фотофиксация прогресса
```

# Состояния экрана

## 1. Данные есть

```text
Показана аналитика за выбранный период.
```

## 2. Данных мало

```text
Пока мало данных для точного анализа

После нескольких тренировок Forma покажет динамику,
рекомендации и сравнение результатов.
```

## 3. Нет тренировок

```text
Тренировок пока нет

и здесь появится ваш прогресс.
```

Кнопки:

```text
[Быстрый старт]

```

## 4. Нет данных тела

```text
Данных тела пока нет

Можно ввести вес и замеры вручную
или подключить умные весы.
```

## 5. Нет фото

```text
Фото прогресса пока нет

Можно сделать первую фотофиксацию.
```

# Что НЕ нужно делать на экране прогресса

Не нужно:

* сравнивать пользователя с другими людьми;
* давать оценки внешности;
* использовать формулировки “плохо выглядишь / хорошо выглядишь”;
* перегружать экран сложной статистикой;
* показывать всё сразу без вкладок;
* делать фокус только на весе тела.

Главный фокус:

```text
личная динамика, сила, регулярность, восстановление и самочувствие.
```

# Ключевые требования

1. Экран показывает личный прогресс пользователя.
2. Основной фокус — сила, регулярность, объём, мышцы, тело и фото.
3. Нельзя сравнивать пользователя с другими людьми.
4. Нельзя делать оценку внешности.
5. Фото прогресса показывается нейтрально, как фиксация по датам.
6. Должны быть вкладки.
7. Должен быть выбор периода.
8. Должна быть сводка главных показателей.
9. Должен быть прогресс по отдельным упражнениям.
10. Должна быть карта нагрузки мышц.
11. Должна быть история веса и замеров.
12. Должна быть галерея фото прогресса.
13. Должны быть достижения и рекомендации Forma.
14. Интерфейс должен быть удобным для большого 4K-монитора.
15. Экран не должен быть перегружен — подробности раскрываются во вкладках.
