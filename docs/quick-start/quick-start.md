# Экран 4 — Быстрый старт

## Назначение экрана

Экран **“Быстрый старт”** нужен, чтобы пользователь мог начать упражнение максимально быстро, без перехода в календарь, конструктор тренировок или полный каталог.

Главная задача экрана:

```text
Выбрать упражнение → подтвердить нагрузку → начать
```

Экран должен быть удобен для ситуации:

```text
Я хочу быстро сделать конкретное упражнение прямо сейчас.
```

---

# Основная логика экрана

Экран не должен быть полноценным каталогом упражнений.
Он должен быть быстрым рабочим инструментом для старта.

Пользователь должен за несколько секунд:

1. увидеть рекомендованные упражнения;
2. выбрать упражнение;
3. проверить прошлый результат;
4. подтвердить вес, подходы, повторы и отдых;
5. нажать большую кнопку `Начать`.

---

# Верхняя системная панель

Верхняя панель такая же, как на остальных экранах Forma.

## Состав панели

```text
Forma
[Алексей]
[Тренажёр готов]
[Левый привод подключён]
[Правый привод подключён]
[Безопасность включена]
[СТОП]
```

## Элементы

| Элемент            | Назначение                   |
| ------------------ | ---------------------------- |
| **Forma**          | Логотип приложения.          |
| **Алексей**        | Текущий пользователь.        |
| **Тренажёр готов** | Общий статус системы.        |
| **Левый привод**   | Статус левого привода.       |
| **Правый привод**  | Статус правого привода.      |
| **Безопасность включена** | Статус системы безопасности. |
| **СТОП**           | Аварийная остановка.         |

---

# Кнопка аварийной остановки

Кнопка:

```text
СТОП
Аварийная остановка
```

## Требования

* всегда видна;
* расположена в правом верхнем углу;
* красная;
* крупная;
* не должна быть похожа на обычную кнопку;
* при нажатии сразу блокирует движение тренажёра.

# Основная зона слева

Левая центральная зона содержит списки упражнений:

1. рекомендованные сегодня;
2. последние упражнения;
3. избранные упражнения.

---

# Блок “Рекомендовано сегодня”

## Назначение

Показывает упражнения, которые лучше всего подходят пользователю прямо сейчас.

Учитываются:

* цели пользователя;
* карта усталости мышц;
* прошлые тренировки;
* чёрный список упражнений;
* доступное оборудование;
* последние результаты.

---

## Пример списка

```text
Рекомендовано сегодня

1. Тяга сверху
   Спина, бицепс
   Причина: спина готова к нагрузке
   Последний раз: 45 кг × 10 × 3
   5 дней назад
   [Выбрать]

2. Тяга к поясу
   Спина
   Причина: подходит под цель “сила + форма”
   Последний раз: 40 кг × 12 × 3
   6 дней назад
   [Выбрать]

3. Сгибание рук
   Бицепс
   Причина: лёгкая усталость, можно выполнить
   Последний раз: 20 кг × 12 × 3
   3 дня назад
   [Выбрать]
```

---

## Карточка упражнения в списке

Каждая строка упражнения содержит:

| Поле                | Пример                  |
| ------------------- | ----------------------- |
| Миниатюра           | Картинка упражнения     |
| Название            | Тяга сверху             |
| Мышцы               | Спина, бицепс           |
| Причина             | Спина готова к нагрузке |
| Последний результат | 45 кг × 10 × 3          |
| Когда выполнялось   | 5 дней назад            |
| Кнопка              | Выбрать                 |

# Блок “Последние упражнения”

## Назначение

Позволяет быстро повторить упражнение, которое пользователь уже делал недавно.

## Пример

```text
Последние упражнения

Жим лёжа
40 кг × 10 × 3
2 дня назад
Грудь: высокая усталость
Лучше снизить нагрузку
[Выбрать]

Присед
60 кг × 10 × 3
3 дня назад
Ноги готовы
Хорошее время для тренировки
[Выбрать]

Тяга сверху
45 кг × 10 × 3
5 дней назад
Рекомендуется
Хорошая готовность
[Выбрать]
```

---

## Поведение

Последние упражнения не нужно скрывать, даже если они сейчас не рекомендуются.

Но если упражнение нагружает уставшие мышцы, нужно показать предупреждение.

Пример:

```text
Грудь: высокая усталость
Лучше снизить нагрузку
```

---

# Блок “Избранные упражнения”

# Правая панель выбранного упражнения

Правая часть экрана — это панель выбранного упражнения.

Она должна быть самой важной частью после списка упражнений.

---

# Блок “Выбранное упражнение”

## Пример

```text
Выбранное упражнение

Тяга сверху

Спина, бицепс
```

## Визуальные элементы

* изображение или анимация упражнения;
* название упражнения;
* целевые мышцы;
* кнопка избранного;
* краткая информация по готовности мышц.

---

# Готовность мышц выбранного упражнения

Для выбранного упражнения показываются мышцы, которые оно нагружает.

## Пример

```text
Готовность мышц

Спина — готова
Бицепс — лёгкая усталость
```

## Цветовая логика

| Статус            | Цвет      | Значение                 |
| ----------------- | --------- | ------------------------ |
| Готова            | зелёный   | Можно выполнять          |
| Лёгкая усталость  | жёлтый    | Можно выполнять умеренно |
| Средняя усталость | оранжевый | Лучше снизить нагрузку   |
| Высокая усталость | красный   | Не рекомендуется         |

# Последний результат

## Пример

```text
Последний результат

45 кг × 10 × 3
5 дней назад
```

## Назначение

Пользователь сразу видит, с каким весом он работал в прошлый раз.

# Рекомендация Forma

Forma должна предложить нагрузку на основе прошлого результата и текущего состояния мышц.

## Пример

```text
Рекомендация Forma

Оставить 45 кг

Можно увеличить до 47.5 кг,
если чувствуете себя хорошо.
```

## Возможные варианты

```text
Оставить текущий вес
Увеличить вес
Снизить вес
Сделать лёгкий подход
```

# Блок “Быстрая настройка”

Здесь пользователь подтверждает основные параметры упражнения.

## Параметры

```text
Вес
Подходы
Повторы
Отдых
Режим нагрузки
```

---

## Вес

```text
Вес: 45 кг

[-5] [-2.5] [ползунок] [+2.5] [+5]
```

## Требования

* вес должен быть крупным;
* должны быть быстрые кнопки изменения;
* ползунок нужен для точной настройки;
* шаг 2.5 кг удобен для силовых упражнений;
* кнопки `-5` и `+5` нужны для быстрых изменений.

---

## Подходы

```text
Подходы: 3

[-] [+]
```

---

## Повторы

```text
Повторы: 10

[-] [+]
```

---

## Отдых

```text
Отдых: 90 сек

[-15] [+15]
```

---

## Режим нагрузки

```text
Режим нагрузки: Обычный вес

[Изменить]
```

## Возможные режимы

На этом экране можно показывать только выбранный режим.

Подробная настройка должна открываться отдельно.

Базовые режимы:

```text
Обычный вес
Помощь вверх
Негативная фаза
Лёгкий режим
```

# Блок “Рекомендация по нагрузке”

Этот блок можно сворачивать.

## Назначение

Объясняет, почему Forma предлагает именно такую нагрузку.

## Пример

```text
Рекомендация по нагрузке

Последний раз:
45 кг × 10 × 3

Сегодня:
45 кг × 10 × 3

Можно увеличить:
47.5 кг, если подходы в прошлый раз были выполнены уверенно.
```

---

# Калибровка

На экране быстрого старта калибровка не выполняется.

Но пользователь должен видеть статус.

## Пример

```text
Калибровка

Потребуется перед упражнением
```

## Возможные состояния

| Состояние                   | Отображение                   |
| --------------------------- | ----------------------------- |
| Калибровка нужна            | Потребуется перед упражнением |
| Есть сохранённая калибровка | Сохранена от 12 мая           |
| Калибровка устарела         | Рекомендуется повторить       |
| Нет данных                  | Будет выполнена перед стартом |

# Блокировка старта

Кнопка `Начать` должна быть недоступна, если:

* упражнение не выбрано;
* тренажёр не готов;
* левый привод не подключён;
* правый привод не подключён;
* активна аварийная остановка;
* есть критическая ошибка;
* нагрузка не задана;
* выбран недоступный режим нагрузки.

# Пользовательский сценарий

## Быстрый запуск рекомендованного упражнения

```text
1. Пользователь открывает “Быстрый старт”.
2. Видит рекомендацию: сегодня лучше спина + бицепс.
3. Видит список рекомендованных упражнений.
4. Нажимает “Выбрать” у упражнения “Тяга сверху”.
5. Справа открывается карточка упражнения.
6. Forma предлагает оставить 45 кг.
7. Пользователь подтверждает 3 подхода × 10 повторов.
8. Нажимает “Начать: Тяга сверху”.
9. Forma проверяет, нужно ли сделать фото прогресса.
10. Далее открывается экран настройки упражнения.
```

# Ключевые требования

1. Экран должен быть рассчитан на большой 4K-монитор.
2. Главный сценарий — начать упражнение максимально быстро.
3. Пользователь должен видеть рекомендованные, последние и избранные упражнения.
4. После выбора упражнения правая панель должна показывать все важные параметры.
5. Основная кнопка `Начать` должна быть большой и очевидной.
6. Экран должен учитывать усталость мышц.
7. Упражнения из чёрного списка не должны попадать в рекомендации.
8. Упражнения из чёрного списка можно запускать вручную с предупреждением.
9. Блок фото прогресса на экране не нужен.
10. Фото прогресса проверяется автоматически после нажатия `Начать`.
11. Калибровка не выполняется на этом экране, только показывается её статус.
12. Если тренажёр не готов, запуск должен быть заблокирован.
13. Настройки веса, подходов, повторов и отдыха должны быть крупными и удобными.
14. Подробные режимы нагрузки не нужно раскрывать на этом экране.
15. Экран должен выглядеть как быстрый и уверенный запуск упражнения, а не как каталог.
