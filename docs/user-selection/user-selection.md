# Экран 1 — Выбор пользователя

## Назначение экрана

Экран выбора пользователя — стартовая точка приложения **Forma** для тренажёра “машина Смита” с нагрузкой от ШВП.

Основная задача экрана — быстро и безопасно выбрать, кто сейчас тренируется, чтобы загрузить персональные:

- рабочие веса;
- историю тренировок;
- прогресс;
- рекомендации;
- карту усталости;
- ограничения;
- настройки безопасности;
- индивидуальные диапазоны движения;
- сохранённые калибровки.

---

## Название приложения

Название приложения:

```text
Forma
```

В левом верхнем углу отображается:

* красивая минималистичная иконка;
* название `Forma`.

Иконка должна выглядеть премиально, современно и технологично.
Желательно использовать стиль, связанный с формой тела, движением, силой или тренажёром, но без буквального изображения штанги.

---

## Основная идея экрана

Экран должен отвечать на один простой вопрос:

```text
Кто тренируется?
```

Пользователь должен выбрать профиль за 1–2 касания.

Главный акцент — на двух основных пользователях:

* Алексей;
* Елена.

Профили `Гость` и `Добавить пользователя` должны быть второстепенными, маленькими и почти незаметными.

---

## Общий визуальный стиль

Стиль экрана:

* тёмный премиальный интерфейс;
* современный фитнес-tech дизайн;
* крупная типографика;
* мягкие свечения;
* стеклянные/полупрозрачные карточки;
* закруглённые углы;
* аккуратные контуры;
* ощущение дорогого домашнего тренажёра;
* фон с едва заметным изображением машины Смита;
* интерфейс рассчитан на большой 4K-монитор.

Экран не должен выглядеть как обычная админка или таблица.
Он должен выглядеть как интерфейс премиального connected-fitness тренажёра.

# Гость

## Роль

Гость нужен для разовой тренировки или демонстрации тренажёра.

Но на экране выбора пользователя он не должен конкурировать с основными профилями.

## Финальное решение

`Гость` должен быть:

* маленькой надписью;
* под основными карточками;
* серым или приглушённым;
* без большой карточки;
* без яркой кнопки;
* визуально второстепенным.

Пример:

```text
Гость
```

или:

```text
👤 Гость
```

Лучшее расположение:

```text
Гость  |  + Добавить пользователя
```

под карточками Алексея и Елены.

## Поведение при нажатии

При нажатии на `Гость` открывается гостевой режим.

Гостевой режим:

* не сохраняет прогресс;
* не влияет на статистику основных пользователей;
* использует ограниченные настройки безопасности;
* может иметь ограничение по максимальной нагрузке;
* использует только базовый режим нагрузки.

Пример ограничений:

```text
Максимальная нагрузка: 30 кг
Режим нагрузки: только базовый
Прогресс: не сохраняется
```

# Добавить пользователя

## Роль

Опция нужна для создания нового профиля, но это редкое действие.

Поэтому она тоже должна быть маленькой и второстепенной.

## Финальное решение

`Добавить пользователя` не должен быть большой карточкой.

Он должен отображаться как небольшая ссылка рядом с гостевым режимом:

```text
Гость  |  + Добавить пользователя
```

## Визуальный стиль

* мелкий текст;
* приглушённый цвет;
* без яркого фона;
* без крупной иконки;
* без большой кнопки;
* не должен отвлекать от карточек основных пользователей.

# Аварийная остановка

На экране всегда должна быть видна кнопка:

```text
СТОП
```

## Расположение

Кнопка размещается в правом верхнем углу.

## Визуальный стиль

* красный цвет;
* крупная;
* хорошо заметная;
* с иконкой предупреждения;
* всегда доступна.

## Поведение

При нажатии:

* движение приводов блокируется;
* тренажёр переходит в безопасное состояние;
* появляется сообщение об остановке;
* дальнейшие действия требуют разблокировки.

Пример сообщения:

```text
Аварийная остановка активна

Движение приводов заблокировано.
Проверьте зону движения и разблокируйте систему.
```

---

# Нижняя панель

Внизу экрана размещаются второстепенные действия.

## Слева

```text
[ Сервисный режим ] [ Диагностика ] [ Настройки ]
```

Эти кнопки должны быть заметны, но не конкурировать с выбором пользователя.

## Справа

Панель состояния безопасности:

```text
Аварийная остановка: активна
Система безопасности: включена
```

---

# Сервисный режим

Кнопка:

```text
Сервисный режим
```

Назначение:

* ручное управление;
* обслуживание;
* настройка приводов;
* проверка движения;
* доступ только взрослому пользователю или по PIN.

---

# Диагностика

Кнопка:

```text
Диагностика
```

Назначение:

* проверка связи с приводами;
* проверка левого и правого каналов;
* проверка рассинхрона;
* проверка аварийной остановки;
* проверка датчиков;
* проверка ошибок.

---

# Настройки

Кнопка:

```text
Настройки
```

Назначение:

* настройки приложения;
* настройки пользователей;
* настройки безопасности;
* PIN-код;
* ограничения гостевого режима;
* тема интерфейса;
* параметры тренажёра.

# Поведение после выбора пользователя

При нажатии на карточку `Алексей` или `Елена`:

1. карточка подсвечивается;
2. профиль загружается;
3. открывается главная страница.

Промежуточный экран лучше не делать слишком долгим.

Возможная короткая анимация:

```text
Загружаем профиль Алексея...
```

Загружаются:

* личные веса;
* история;
* карта усталости;
* рекомендации;
* настройки безопасности;
* запланированная тренировка.

---

# Что не нужно показывать на этом экране

На экране выбора пользователя не нужно показывать:

* подробные графики;
* полный календарь;
* каталог упражнений;
* историю всех тренировок;
* настройки нагрузки;
* калибровку;
* подробную диагностику;
* длинные описания.

Этот экран должен оставаться простым.

Его главная задача:

```text
Выбрать пользователя и безопасно перейти дальше.
```

1. Экран должен быть рассчитан на большой 4K-монитор.

5. Название приложения — `Forma`.
6. В левом верхнем углу должна быть красивая иконка Forma.
7. Кнопка `СТОП` всегда должна быть видна.
8. Статус тренажёра всегда должен быть виден.
9. Интерфейс должен выглядеть премиально, современно и удобно.
10. Экран не должен быть перегружен.
