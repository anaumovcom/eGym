# Экран 5 — Сегодняшняя тренировка

## Назначение экрана

Экран **“Сегодняшняя тренировка”** нужен для просмотра и запуска тренировки, запланированной на сегодня.

Он отвечает на вопросы:

```text
Что сегодня делать?
В каком порядке?
С какими весами?
Сколько подходов и повторов?
Какие мышцы будут нагружены?
Можно ли начинать прямо сейчас?
```

Это не конструктор программы.
Это экран **исполнения плана на сегодня**.

---

# Главная идея экрана

Пользователь открывает экран и сразу понимает:

```text
Сегодня: Спина + бицепс
5 упражнений
18 подходов
≈ 45 минут

Тренажёр готов.
Можно начинать.
```

Главная кнопка:

```text
Начать тренировку
```

Если тренировка уже начата:

```text
Продолжить тренировку
```

---

# Что важно для этого экрана

Экран должен показывать не только список упражнений, но и:

* готовность пользователя;
* готовность тренажёра;
* усталость мышц по этой тренировке;
* упражнения по порядку;
* веса, подходы, повторы, отдых;
* статус каждого упражнения;
* возможность заменить упражнение;
* возможность немного изменить нагрузку;
* общий прогресс тренировки;
* понятный путь к первому упражнению.

---

# Общая структура экрана

Экран состоит из блоков:

1. Верхняя системная панель.
2. Левое меню.
3. Заголовок тренировки.
4. Общая сводка тренировки.
5. Кнопка старта / продолжения.
6. Список упражнений.
7. Правая панель выбранного упражнения.
8. Карта мышц тренировки.
9. Прогресс выполнения.
10. Нижние действия.

---

# Верхняя системная панель

Такая же, как на остальных экранах Forma:

```text
Forma  [Алексей]  [Тренажёр готов]  [Левый привод: подключён]  [Правый привод: подключён]  [Защита активна]  [СТОП]
```

Кнопка `СТОП` всегда видна и доступна.

# Состояния главной кнопки

## 1. Тренировка ещё не начата

```text
Начать тренировку
```

Переход:

```text
Сегодняшняя тренировка
→ Проверка необходимости фото прогресса
→ Предстартовая проверка
→ Карточка первого упражнения
→ Калибровка
→ Выполнение упражнения
```

---

## 2. Тренировка уже начата

```text
Продолжить тренировку
```

Переход:

```text
Сегодняшняя тренировка
→ Текущее упражнение / следующий подход
```

---

## 3. Тренировка завершена

```text
Открыть итог тренировки
```

---

## 4. Тренажёр не готов

```text
Запуск недоступен
```

И рядом причина:

```text
Правый привод не подключён
```

# Проверка фото прогресса

На этом экране **не нужно показывать отдельный блок фото прогресса**.

Но после нажатия `Начать тренировку` система проверяет, нужно ли сделать фото.

Если нужно:

```text
Сегодняшняя тренировка
→ Фотофиксация прогресса
→ Предстартовая проверка
→ Первое упражнение
```

Если не нужно:

```text
Сегодняшняя тренировка
→ Предстартовая проверка
→ Первое упражнение
```

# Карточка упражнения в списке

Каждое упражнение должно быть строкой или карточкой.

## Содержимое карточки

```text
1. Тяга сверху

Целевые мышцы:
спина, бицепс

План:
45 кг · 3 подхода × 10 повторов

Отдых:
90 сек

Режим нагрузки:
Обычный вес

Калибровка:
Потребуется перед упражнением

[Начать] [Подробнее] [Заменить]
```

---

# Статусы упражнений

У каждого упражнения должен быть статус.

| Статус               | Значение                                                 |
| -------------------- | -------------------------------------------------------- |
| **Следующее**        | Первое упражнение, которое нужно выполнить.              |
| **Далее**            | Упражнение стоит позже в плане.                          |
| **В процессе**       | Упражнение начато, но не закончено.                      |
| **Выполнено**        | Все подходы упражнения выполнены.                        |
| **Пропущено**        | Пользователь пропустил упражнение.                       |
| **Заменено**         | Упражнение заменено на другое.                           |
| **Не рекомендуется** | Упражнение конфликтует с усталостью или чёрным списком.  |
| **Недоступно**       | Нельзя выполнить из-за состояния тренажёра или настроек. |

---

# Пример статуса в тренировке

```text
1. Тяга сверху
   Следующее
   [Начать]

2. Тяга к поясу
   Далее

3. Сгибание рук
   Далее
```

После выполнения первого упражнения:

```text
1. Тяга сверху
   Выполнено: 45 кг × 10 × 3

2. Тяга к поясу
   Следующее
   [Начать]
```

# Правая панель выбранного упражнения

Когда пользователь нажимает на упражнение в списке, справа открывается подробная карточка.

## Пример

```text
Выбранное упражнение

Тяга сверху

Целевые мышцы:
спина, бицепс

План:
45 кг · 3 × 10

Последний результат:
45 кг × 10 × 3
5 дней назад

Рекомендация Forma:
оставить 45 кг

Готовность мышц:
спина — готова
бицепс — лёгкая усталость

Калибровка:
потребуется перед упражнением

[Начать упражнение]
[Открыть карточку]
[Заменить]
```

# Быстрое редактирование упражнения

На этом экране можно разрешить **лёгкое редактирование**, но не полноценный конструктор.

## Можно менять

* вес;
* подходы;
* повторы;
* отдых;
* режим нагрузки;
* порядок упражнений;
* пропустить упражнение;
* заменить упражнение.

## Не нужно здесь делать

* создание новой программы с нуля;
* сложный редактор всей тренировки;
* настройку тренажёра;
* технические параметры ШВП.

Для глубокого редактирования:

```text
[Открыть в конструкторе]
```

---

# Замена упражнения

Очень полезная функция.

## Когда нужна

* упражнение не хочется делать;
* мышца устала;
* упражнение в чёрном списке;
* не подходит оборудование;
* пользователь хочет аналог.

## Пример

```text
Заменить упражнение: Жим лёжа

Причина:
грудь имеет высокую усталость.

Рекомендуемые замены:
- Тяга сверху
- Тяга к поясу
- Сгибание рук
```

Для текущей тренировки “Спина + бицепс” замены должны быть в той же логике тренировки.

---

# Карта мышц тренировки

На этом экране карта усталости не обязательно такая большая, как на главной, но полезно показать:

```text
Какие мышцы будут нагружены этой тренировкой
```

## Пример

```text
Мышцы тренировки

Спина — основная нагрузка
Бицепс — основная нагрузка
Предплечья — дополнительная
Кор — лёгкая нагрузка

Грудь — не нагружается
Трицепс — почти не нагружается
```

Можно показать маленькую SVG-карту тела с подсветкой именно мышц сегодняшней тренировки.

# Прогресс тренировки

Если тренировка уже началась, нужно показывать общий прогресс.

## Пример

```text
Прогресс тренировки

Выполнено:
2 из 5 упражнений
7 из 18 подходов

Осталось:
≈ 27 минут

Следующее:
Сгибание рук
```

## Визуально

* прогресс-бар;
* процент выполнения;
* выполненные упражнения;
* оставшееся время;
* следующий шаг.

# Блок состояния тренажёра

Небольшая карточка:

```text
Тренажёр

Готов к работе

Левый привод: подключён
Правый привод: подключён
Система безопасности: включена
Калибровка: перед каждым упражнением

[Диагностика]
```

Если есть проблема:

```text
Запуск заблокирован

Причина:
нет связи с правым приводом

[Открыть диагностику]
```

# Блок предупреждений

Если в плане есть проблемы, нужно показать их до старта.

## Примеры

### Упражнение нагружает уставшие мышцы

```text
Внимание

Жим лёжа нагружает грудь,
а грудь сегодня имеет высокую усталость.

Рекомендуется заменить упражнение
или снизить нагрузку.
```

---

### Упражнение в чёрном списке

```text
Упражнение в чёрном списке

Тяга к подбородку находится в чёрном списке пользователя.
Оно не должно попадать в автоматически созданные программы.

[Заменить упражнение]
[Оставить вручную]
```

---

### Тренировка слишком тяжёлая

```text
Тренировка может быть тяжёлой

Общий объём выше среднего для этой недели.
Можно снизить количество подходов.
```

# Нижние действия

Внизу экрана можно расположить вторичные кнопки:

```text
[Изменить тренировку]
[Сохранить как программу]
[Перенести тренировку]
[Завершить / удалить из сегодня]
```

Но главный акцент всё равно на:

```text
[Начать тренировку]
```

# Сценарии пользователя

## Сценарий 1 — Начать тренировку

```text
Сегодняшняя тренировка
→ Начать тренировку
→ Проверка фото прогресса
→ Предстартовая проверка
→ Первое упражнение
→ Калибровка
→ Выполнение упражнения
```

---

## Сценарий 2 — Начать конкретное упражнение

```text
Сегодняшняя тренировка
→ Выбрать упражнение
→ Начать упражнение
→ Предстартовая проверка
→ Калибровка
→ Выполнение упражнения
```

Если упражнение не первое, приложение может спросить:

```text
Начать это упражнение вне очереди?
```

---

## Сценарий 3 — Заменить упражнение

```text
Сегодняшняя тренировка
→ Упражнение
→ Заменить
→ Выбор аналога
→ Подтвердить замену
→ Обновлённый план
```

---

## Сценарий 4 — Изменить вес

```text
Сегодняшняя тренировка
→ Выбрать упражнение
→ Изменить вес
→ Сохранить в сегодняшней тренировке
```

Можно спросить:

```text
Применить только сегодня или сохранить как новый рабочий вес?
```

---

## Сценарий 5 — Продолжить прерванную тренировку

```text
Сегодняшняя тренировка
→ Продолжить тренировку
→ Последнее незавершённое упражнение
```

---

## Сценарий 6 — Завершить тренировку досрочно

```text
Сегодняшняя тренировка
→ Завершить тренировку
→ Подтверждение
→ Итог тренировки
```

На этом экране лучше разрешить быстрые изменения:


# Взаимодействие с калибровкой

На этом экране только показываем статус:

```text
Калибровка: потребуется перед упражнением
```

или:

```text
Калибровка: сохранена
```

Сама калибровка происходит позже:

```text
Сегодняшняя тренировка
→ Упражнение
→ Калибровка упражнения
```

# Важное по минимальной высоте

Минимальная безопасная высота **не хранится в сегодняшней тренировке как общая настройка**.

Она зависит от:

* конкретного упражнения;
* пользователя;
* положения тела;
* скамьи;
* хвата;
* выбранной амплитуды;
* текущей калибровки.

Поэтому в плане можно показывать только:

```text
Калибровка потребуется
```

а точные нижняя и верхняя точки задаются на экране калибровки.

# Ключевые требования

1. Экран должен быть рассчитан на большой 4K-монитор.
2. Главный сценарий — начать или продолжить сегодняшнюю тренировку.
3. Список упражнений должен быть понятным и идти по порядку.
4. У каждого упражнения должны быть вес, подходы, повторы, отдых и статус.
5. Должна быть большая кнопка `Начать тренировку`.
6. Если тренировка уже начата, должна быть кнопка `Продолжить тренировку`.
7. Если тренажёр не готов, запуск должен быть заблокирован.
8. Фото прогресса не показывается как блок, но проверяется перед стартом.
9. Калибровка не выполняется на этом экране, только показывается её статус.
10. Минимальная высота зависит от упражнения и задаётся на экране калибровки.
11. Нужно позволить заменить упражнение или облегчить тренировку.
12. Подробное редактирование программы должно быть в конструкторе.
13. Экран должен показывать мышцы, которые будут нагружены тренировкой.
14. Упражнения из чёрного списка не должны попадать в автоматически созданные тренировки.
15. Интерфейс должен оставаться премиальным, тёмным, крупным и удобным для сенсорного управления.
